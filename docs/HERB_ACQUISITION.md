# 丹方用途与药材取得难度

## 问题与边界

原定向材料秘境只按药材品阶计算境界：三品需要金丹初期、四品需要元婴初期、五六品需要化神。126 张实际丹方中，17 张用到高于自身品阶的药材，98 张的至少一种材料晚于它的开炉阶段才能取得。筑基丹的四种三品材料因此要先到金丹，形成突破准备闭环。

本次只调整炼丹材料的取得阶段及与真实开炉阶段不一致的丹炉购买资格。丹方用量、丹药效果、药材品阶和价格、情报价格与十份终点奖励、制作和灵田时长均保持。高阶炼器材料仍按原品阶探索难度。普通坊市仍只出售一二品药材；提早取得高品药材须探索定向秘境或到对应野外生境采集。

## 权威规则

`crafting/herb_acquisition.*` 以稳定 `RecipeId`、`HerbId` 提供统一查询：

1. `mfEarliestRecipeCraftStage` 遍历合法小境界，用现有 `artTier` 检查丹方品阶，并确认目录中有该阶段可用且容量满足真实配料总数的丹炉。各品丹的通常最早阶段是 0、0、2、5、8、11；如容量不足，查询继续检查后续阶段。
2. 普通丹方的用途阶段为最早开炉阶段；突破丹额外取 `mfBreakthroughPillStage(RecipeId)` 的准备阶段与最早开炉阶段的较小值。准备表由服药模块统一维护，朝元丹为金丹后期（stage 8）。
3. 每种药材的取得阶段，取原取得阶段与所有实际使用该药材的丹方用途阶段的最小值。一二品原阶段是 0，其余原阶段是 `min(12, (grade - 1) × 3)`。未被更早丹方使用的高品材料保留原阶段。

输入未知 ID 返回 -1，不授予资格。规则仅在首次查询时从不变目录建立缓存，不创建游戏、不推进时钟或随机数。历史 `RecipeDef.ingredients` 仍用名称存储，读取目录的适配边界只通过既有解析器转换为 HerbId；领域规则不按中文丹名、效果文案或地点显示名判定。

`shop::buyableFurnaces` 与 `shop::buyFurnace` 都用 `artTier`。三至六品炉在 2、5、8、11 阶段可购，修复最高六品炉永远买不到及突破准备期无同品炉具的闭环，不更改炉具价格、容量或定义。

## 来源接线

- 情报选项、实际生成的入口难度、定向目标存档合法性均使用相同的材料取得阶段。入口仍冻结 `max(购买时玩家境界, 最低取得阶段)`；已存在的较高难度入口不降低。提前购买与进入门槛依旧分离。
- `mfGatherableHerbs` 供地点采药、月度采药计划、药谷奇遇奖励共用。野外草药须同时达到取得阶段并符合 `content/herb_habitats.*` 的明确 LocationId → HerbId 生境表。十处宁州山谷保留原来源，原海外生境由已有 `sea` 地点代表。修改地点或药材显示名不会改变可采资格。
- 未知地点不给采集池。城市、山门和无对应生境的野外地点只保留原低品草药兜底，不把高品材料扩散到任意地点。
- `mfIsPlantHerb` 的稳定妖丹 ID 分类是草药过滤的唯一入口；妖丹不进入野采池或秘境沿途低阶草药池。妖丹材料仍可通过需要战斗的指定情报秘境取得，难度按丹方实际用途计算。
- 秘境沿途伴随材料仍最多二阶，目标材料的高品十份属于终点奖励，不改变沿途收益规模。

| 血莲精、鸡冠草、银精芝、白沉脂 | 元婴初期 9 | 炼气后期 2 | 每份 112 |
| 补天芝、乌椆木、炼血珠、玉龙参 | 金丹初期 6 | 炼气初期 0 | 每份 63 |

## 回归

`tests/test_herb_acquisition.cpp::mfRunHerbAcquisitionTests` 汇总完整有效丹方的资格、实际配料可得性和突破准备期材料；覆盖筑基丹四材料的真实情报、入场和存读档，草药生境及妖丹排除，城市和野外真实采药回调，同品丹炉纯目录/真实购买/真实开炉与拒绝原子性。`test_intel_purchase` 保留完整高阶情报目录交易回归，并按新的实际用途阶段判断入场门槛。

静态数据保留原外部JS导出路径，再由官方生成器应用`data/reference_overrides.json`中的本地规则，不手改`data/reference_tables.h`。2026-10-16丹药改版后有效目录为123丹方、155药材；诱妖液、驱妖液以及其独用药材诱妖草/霸王花停止生成，海域生境同步移除两味药材ID。新丹方通常自动参与用途推导；新增突破丹须登记统一准备表，新增野外生境须显式登记稳定地点与药材ID。
