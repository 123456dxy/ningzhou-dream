# 丹药实际效果与检查边界

当前有效目录为123味丹药、14种效果分类。artUsePill / artApplyPill与只读artPillUseInfo共用服丹计划；前端只展示实际报价。太素祛邪丹、诱妖液、驱妖液退休，其独用药材诱妖草与霸王花停止生成。

## 用途与丹毒

| 用途 | 每枚丹毒 | 稳定效果键 |
| --- | ---: | --- |
| 回复、修为 | 1 | heal、xp |
| 悟道、永久属性 | 2 | dao、points、apt、insight、body、heart、mind、speed |
| 战斗准备、突破、延寿 | 4 | combat、breakthrough、life |
| 化毒 | 0 | detox |

同用途所有品阶毒值相同，越阶不额外加毒。progression/pill_poison_rules提供唯一配置，未知用途拒绝；参考表保留的源毒量不决定实际结算。poisonAfter / poisonDelta是扣除化毒效果后、受0至100限制的实际数值。既有丹毒原样保存，不按历史次数重算。

丹毒超过20开始降低修炼效率。达到80后仅允许化毒或准备下一战的战斗丹；普通服丹仍被阻止。自然化毒统一每世界年5点，丹道不再额外增加。化毒四档为10/20/40/80，均不增加自身丹毒。

## 气血与永久属性

疗伤丹共8个稳定ID、5档效果：一阶40、二阶200、三阶800、四阶2000点、五阶回满。5501.value=0是回满标记，按当前真实上限计算，不使用固定大数；耐药次数保留。玩家health为绝对点数。NPC持久health仍为0至100，服丹前按NPC真实上限（含普通修士1.45倍率）换成点数，结算后转换回百分比。

体魄丹5209/5306/5417/5515分别永久增加3/7/20/40气血基数，写入BaseHealthBonus；与境界、筑基基数相加后再经2.4、功法和体魄乘区。目录写基础值，服用预览写当前构筑的真实上限增量。无业务累计上限，仍受每味耐药次数和整数安全范围限制。旧hpBonus保留倍率语义，新服用不再写它。

护甲位提供每回合护盾，沿用30%总盾上限，不再增加气血倍率。开局丹药盾与护甲进入现有护盾通道，不重复增加气血。

寿元丹五档为10/20/40/70/120年。PillLifeBonus独立记录丹药贡献，最多500年；lifeBonus保存天赋和丹药合计，长寿天赋不占丹药额度，突破保留总加成。资质丹取消本世10点额度和总属性200截断，悟性丹取消总属性200截断，仍受每味耐药与安全整数范围约束。其它正向奖励不得降低已经超过普通软上限的属性。

## 战斗准备

| 准备 | 本地实际效果 |
| --- | --- |
| 伤害 | 下一战伤害加成10% |
| 护盾 | 开局增加气血上限20%的盾，总开局盾至多30% |
| 减伤 | 额外减伤12%，总减伤至多35% |
| 剑气 | 开局增加2剑气，仍受8层上限限制 |
| 灵力 | 仅开局增加，当前本地尺度至多1点，容量和每轮恢复不变 |
| 遁速 | 下一战先手及撤离判定增加10 |

准备按稳定ID分派，不匹配中文文案。龟甲丹5121、玄武丹5225属于减伤；同类覆盖，不叠加。下一场至多服用三枚（同类覆盖也计次数）；NPC真实战前至多服三枚有实际收益的战斗丹。高丹毒可以超载，库存、耐药和丹毒仍真实结算。准备在真实开局后清空场外字段，保存/读取不重复扣药，下一场不免费重放。

突破丹仅在对应境界服用：5205→2；5220至5224/5317→5；5406/5421/5422/5424/5425→8；5520至5522→11。5205提供1份筑基丹准备，五行路线初始随机2气、周天路线初始真气+15，计入6份上限，不再展示假成功率。其余三档保留对应境界6个百分点准备，其它突破不新增玩法。

## 修为丹

标称值保留round(sqrt(参考值) × 4)。普通小境单次吸收上限仍为round(当前需求 ÷ CultivationUnits::Scale × 25%)，例如炼气初期上限28；临近圆满只结算余量，不把正常修炼扩单位误用于提高丹药。化神需求为0时采用前一境界的单次吸收上限并允许积累修为，避免极境收益恒为0。先天异脉继续拒绝修为丹。

mfCompletePillEffect输出角色无关标称能力，目录读catalogEffect，当前预览读effect / effectValue，两套前端不复制公式。

## NPC、兼容与数据

NPC按剩余50/25/10/5年分档续命；10年内仅考虑化毒与续命。日常先进行化毒阶段，随后在服后丹毒不超过40的范围持续服用，取消固定三枚上限；进入普通服药后不会再次化毒绕过闸门。真实年度行动按正常成品报价采购适用的化毒/续命丹；初始背包按丹毒和剩余寿元加权。查询、构筑预览和读档不服丹、不采购。

新持久字段、退休ID、旧倍率、检查点与留影由持久化层统一迁移及校验。原始两份dump加受版本控制的data/reference_overrides.json进入官方tools/extract-data.py；不直接编辑生成表。生成链覆盖19张表，--check逐字节验证。

旧NPC前缀与裸ID化毒库存统一合并到potion:5420，退休探索丹药及药材清退。旧在途5519制作仅改目的ID到5420，保留已付费用、剩余时间、概率和产量。5318/5319旧在途制作取消：退冻结已付灵石，每炉退幻心草2份及混元果/鸡冠草1份；退休主药旧本地价112灵石/份折返。按在途期间不能换炉/改节点的限制推断原磨损条件，退回已扣耐久且至多40；已过去天数不退，不发成丹或经验。退款、辅材、数量、paid及溢出先核算；坏合同拒绝整个读档，成功保存后不会重复补偿。
