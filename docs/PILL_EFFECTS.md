# 丹药实际效果与检查边界

本次覆盖当前目录全部 126 味丹药、16 种效果分类。服药入口仍为 `artUsePill` / `artApplyPill`，只读报价与实际执行共用 `pillPlan`。两味错误分类的防御丹按已有减伤规则修正；其余丹药数值、耐药次数、丹毒、永久属性上限与战斗灵力尺度保持原有规则。

## 本次修复

- 龟甲丹 `5121`、玄武丹 `5225` 原先因为中文关键词未匹配而错误进入攻击准备。现在生成本地已有的 12% 减伤准备，实际受到的伤害下降；不新增原游戏的固定减伤状态或存档字段。
- 朝元丹 `5406` 改为金丹后期（序号 8）服用，准备结婴，避免误用于筑基后期的结丹准备。
- 战斗准备类型和突破门槛按稳定丹方 ID 决定。改名称或源说明不会改变效果。
- 开局灵力类丹药按当前本地尺度提供最多 1 点开局灵力，实际增量受已准备状态、被动与容量限制。容量与每轮恢复量不会增加；目录和实际预览区分完整能力与当前增量。
- 疾行准备的说明同时列出先手和撤离判定，与战斗逻辑一致。
- 服药纪事记录实际属性变化，而非完整能力；丹毒记录净变化，化毒不再显示“丹毒 +0”。

## 同类服用与下一场生效

| 本地准备 | 实际用途 | 同类再次服用 |
| --- | --- | --- |
| 伤害 | 本场伤害倍率加成 10% | 覆盖为同一值，不相加 |
| 护盾 | 开局增加相当于斗法气血上限 20% 的盾，总开局盾上限 30% | 覆盖，不追加第二份开局盾 |
| 减伤 | 本场额外减伤 12%，总减伤仍受 35% 上限限制 | 覆盖，不相加 |
| 剑气 | 开局增加 2 剑气，仍受 8 层上限限制 | 覆盖，不相加 |
| 灵力 | 仅开局增加，当前本地尺度最多 1 点 | 覆盖；容量和每轮恢复不变 |
| 遁速 | 本场先手及撤离判定增加 10 | 覆盖，不相加 |

不同准备类别可以共存。玩家在耐药允许、丹毒未阻断时可以重复服用同类，但库存、服用次数和丹毒仍会结算；实际预览会明确显示收益为零，不改变这条既有允许规则。NPC 只选择有实际收益的丹药，因此不浪费同类重复准备。

准备在真实对局开局完成后清空场外字段，效果进入该场 `Battle`。场内保存与读档保留已生效效果，不重复消耗丹药；未服新丹的下一场不会再获得旧准备。开局灵力仅在首轮生效，护盾随后按正常吸收和回合规则处理，其他效果遵循原战斗状态生命周期。

## 权威规则和接口

- `src/core/progression/arts.cpp`：统一服丹报价、验证、执行与实际纪事。
- `mfCompletePillEffect(Recipe)`：角色无关的本地标称能力。修为丹继续使用既有 `round(sqrt(参考值) × 4)` 换算，不把原游戏参考修为直接当成本地效果。`artPillEffect(Player, Recipe)` 仍为考虑当前小境及天赋的基础药效；`artPillUseInfo` 再按距圆满余量生成实际预览，与执行共用计划。
- `src/core/arts.h`：既有公开接口，以及新增 `mfBreakthroughPillStage(RecipeId) -> optional<int>`。非突破丹或未登记 ID 返回空值，材料获得目标可以复用此表。
- `src/core/combat/battle.cpp`：准备进入真实战斗、施术伤害、敌方来伤、开局后消费准备。本次不修改此文件。
- `src/core/social/npc_consumables.cpp`：复用玩家服丹计划，选择适用且存在收益的丹药。本次不修改此文件。

突破准备门槛：`5205 -> 2`；`5220..5224 / 5317 -> 5`；`5406 / 5421 / 5422 / 5424 / 5425 -> 8`；`5520..5522 -> 11`。仍沿用本地统一 6 个百分点大境界突破准备，不引入原游戏的突破阶段卡牌机制。

原始参考表中的元素灵根权重、状态免疫、固定技能减伤等原游戏描述，不能当成本地已实装效果。本地目录应显示 `PillUseInfo` / `artPillEffect` 的权威说明；本次仅修复上述明确错误，不据源文案扩充整套状态系统。

## 修为丹标称值与当前吸收

目录的 `catalogEffect` 显示本地标称值，修为丹另提供数值字段 `catalogEffectValue`。它不随当前角色的境界、圆满程度或先天异脉变化；实际收益仍由 `effect` / `effectValue` 展示。当前服用的 `usage` 同时列明标称药效、本小境25%的单次吸收上限及距圆满余量。小境上限沿用四舍五入，例如炼气初期 `round(110 × 25%) = 28`。

| 丹药 | 品阶 | 本地标称修为 | 炼气初期、修为0实际吸收 | 元婴初期、修为0实际吸收 |
| --- | --- | --- | --- | --- |
| 洗髓丹 `5002` | 一阶 | 54 | 28 | 54 |
| 养气丹 `5102` | 二阶 | 94 | 28 | 94 |
| 天元神丹 `5502` | 六阶 | 3083 | 28 | 3083 |

此前完整目录使用当前角色小境调用 `artPillEffect`，将当前吸收上限误写成完整能力。修复把标称查询放回领域模块，并让坊市、工坊、全量丹药目录共用；真实服丹的数值、丹毒与耐药规则保持既有行为。临近圆满剩余1点时这三味丹药均只结算1点；先天异脉仍拒绝服用修为丹。

本项影响记录：权威入口为 `mfCompletePillEffect` / `artPillEffect` / `artPillUseInfo`；接口视图消费标称查询，桌面 `renderPillEffect` 的完整目录与行囊当前效果分别读取 `catalogEffect` 与 `effect`，不增加前端公式。NPC 继续走 `artApplyPill` 共用计划。已搜索这些入口、`catalogEffect` / `baseEffect` / `effectValue` / `pillCatalog`、两套前端、测试、API索引、HTTP文档与生成输入；不改路由、ID、存档字段或参考表，无新增/删除源文件。新增定向用例位于 `tests/test_catalog_display.cpp`，覆盖一二六阶、晋阶、圆满余量、异脉拒绝、只读状态与旧缺省字段恢复。

## 实际验证

`tests/test_pill_effects.cpp` 使用真实规则入口与独立角色，验证全部丹方的库存、耐药、丹毒及对应属性或准备写入；六类准备和两味修正防御丹的真实开局、重复覆盖、一次消费、下一场不重放；真实出牌伤害增加与真实敌方回合伤害降低；NPC 六类战前服丹；无效动作全状态原子性；场外、在战和旧缺省字段的存档行为。

针对文案、分类、朝元丹门槛及纪事的修复先观察到独立红测试失败，再修复并复测。全库结果由本轮完整构建和统一测试报告给出，不能用过去的通过记录替代。
