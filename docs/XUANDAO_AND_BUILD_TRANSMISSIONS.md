# 玄道宗与常态完整传承

玄道宗沿用既有宁州东南地图地点 `xuandao`，现在是第六个可实际拜入的宗门，主传承为阵道和五行剑。入门、拜师、宗门任务、贡献、俸禄使用已有流程。入门考核是非致命的五行试剑，胜出给予五行剑诀抄本与金灵剑。

初始推荐和进阶推荐共用八个稳定流派 ID。初始来自 `artBuilds()`，进阶来自 `content::mfAdvancedBuilds()`；六宗进阶功法与神通直接派生自唯一 NPC 完整模板，避免显示推荐和实际敌人维护两份数据。剑气与神识的进阶建议使用已有真实功法神通，由玩家自行配装。

“完整传承”表示更完整的可配置资源，不保证对任何敌人和牌序必胜，也没有隐藏增伤倍率。实际装备仍受境界、辅修与神通槽位限制。初始/进阶效果需用同境界、同种子、同对手和同操作策略对照，不能仅凭多装几张卡断言永远更强。

## 常态人物与授业

`content::mfEnsureSectTransmissions(Game&)` 在建角、年度更新和旧世界缺第六宗的读档初始化中补齐账簿与传承者。不在只读视图中调用，不消耗随机数、不改玩家资源和在途战斗。每宗优先选择已有存活人物中境界最高者，同境按稳定 ID；现有合法传承保留。宗门没有任何存活修士时，生成一名确定性的元婴传承执教作为恢复入口。

完整老师的请教知识包含其模板全部功法神通，不受当前辅修装备槽裁剪。请教仍须满足双方境界、同地、好感、交情和灵石，每月向每位老师最多三项；逐本/逐张学习，功法仅获得第一层，后续升层仍需真实修习。初始档不能通过查看完整目录免费获得满级构筑。

## 只读接口字段

| 字段 | 内容 |
| --- | --- |
| `advancedBuilds[]` | 八组 `id/name/dao/desc/tier/manuals/spells/nodes`；`tier=advanced` |
| `championTeachers[]` | 活跃老师的 `id/name/profileId/buildId/buildName/sect/stage/realmName/location/locationName/here` |
| `nearby[].buildTier` | 传承身份为 `advanced`，一般修士为 `initial` |
| `nearby[].advancedBuildId` | 指向同一八流派稳定 ID |
| `nearby[].transmission` | 完整老师的模板清单与逐项请教说明 |

字段只展示事实和位置，导航仍走真实赶路，授业执行重新校验当前位置与人物状态。

## 影响范围与验证入口

稳定 ID 扩展同时覆盖宗门枚举、解析、显示名、静态宗门目录、地图服务、考核、生成名册、藏经阁与 NPC 默认大道。没有修改生成参考表、手机端、认证、多人或天机大比实现。新增状态字段均为派生视图；没有新增存档字段。旧档世界缺玄道宗时仅普通读档初始化补齐，独立留影不补世界。

定向测试入口 `tests/test_xuandao_sect.cpp::mfRunXuandaoSectTests` 覆盖注册、常态传承者、纯查询、授业目录、真实结算、重复拒绝、藏经阁隔离和旧世界迁移往返。工程统一由本轮主任务同步和构建；浏览器交互与同种子强度对照需另行记录实际结果。
