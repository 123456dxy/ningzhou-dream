# 流派构筑、传承渠道与特殊秘境改版提案

日期：2026-10-14。状态：**供讨论的设计方案，尚未实施**。本文件没有修改战斗数值、内容目录、NPC 牌池、秘境掉落或玩家存档；也没有宣称现有流派已完成数值平衡。

本轮执行范围仍是便利功能；此方案供下一轮玩法改版评审。闭关修炼效率、天机大比、手机端与联机不属于方案实施范围。方案按 `BACKEND_ARCHITECTURE.md`、`CODING_STANDARDS.md` 及 combat / progression / exploration / social 模块 README 的职责边界组织。

## 1. 已明确的目标与边界

用户已明确：

- 完善现有战斗流派的特色与构筑，普通宗门 NPC、精英传承 NPC 也获得相应完整构筑。
- 新增部分更强的抽牌、回灵等组合，**只给玩家使用，真实 NPC 不获得这些核心与组合**。
- 功法和神通的取得渠道应同样便利，能有目的地拼齐构筑。
- 设计特殊秘境，参考《杀戮尖塔》的怪物机制；每个大境界有对应秘境。最初提出通关删一攻一防，后续提出给选定卡牌“固有 / 保留”等附魔作为替代候选，**尚未批准取代删牌**。本文以附魔为主建议、删牌为互斥备选是设计建议，均尚未实施。
- 突破到下一大境界后，不能再进入上一大境界的特殊秘境。
- 复用无尽海、天魔眼等现有地图地点；炼气 / 筑基 / 金丹 / 元婴 / 化神分别每 **10 / 20 / 50 / 100 / 200 年**开启一次。
- 天机阁从售卖材料秘境位置改为售卖**功法线索秘境**。
- 本轮先提出方案，暂不改变上述玩法。便利功能修改后本地 Git 保存另行处理。

本文其余内容均是推荐规则，尤其附魔奖励的最终选择与上限、开放窗口、首通的去重方式、错过旧境奖励后的补选、玩家专属功法的层级与费用，仍需要评审。所有示例卡名、敌人名和效果均为本项目原创建议，并非《觅长生》或《杀戮尖塔》的现成内容。

## 3. 参考来源与采用的设计原则

《杀戮尖塔》的官方介绍强调选择互相配合的卡牌、在风险不同的路线之间取舍，以及每次遇到不同敌人、遗物和首领。本项目借鉴这些选择，不复制其完整游戏数值。[Steam 官方商店介绍](https://store.steampowered.com/app/646570/Slay_the_Spire/)

敌方意图在行动前展示，玩家据此决定输出、防御或准备；意图应成为真实结算的预告，不是只显示怪物攻击力。[Slay the Spire 社区 Wiki：Intent](https://slay-the-spire.fandom.com/wiki/Intent)

三个有针对性的机制参考：守护者依据受伤切换攻守阶段；地精大块头对技能出牌作出反应；时间吞噬者根据出牌次数触发变化。这些参考说明“怪物检查构筑的不同能力”，**不意味着本项目照搬反伤、12 张强制结束回合或无限增强**。本方案采用有上限、可预告、有补偿窗口的改写。[The Guardian](https://slay-the-spire.fandom.com/wiki/The_Guardian)、[Gremlin Nob](https://slay-the-spire.fandom.com/wiki/Gremlin_Nob)、[Time Eater](https://slay-the-spire.fandom.com/wiki/Time_Eater)

《觅长生》官方创建的 BWIKI 将功法和神通均列出请教、特殊、购买、兑换等来源；同一流派既有宗门传承，也有具体师长和交易入口。采用的是“同一构筑的功法与神通都能被主动追踪”的组织方式，不复制条目的实际费用和效果。[觅长生 BWIKI：功法](https://wiki.biligame.com/mcs/%E5%8A%9F%E6%B3%95)、[觅长生 BWIKI：神通](https://wiki.biligame.com/mcs/%E7%A5%9E%E9%80%9A)

资料核对日期为 2026-10-14。上述 Wiki 内容为社区维护数据；Steam 为发行方介绍。部分 wiki.gg / Fandom 页面直接打开受限制，具体怪物资料通过搜索返回的页面正文核对，不能将其视为当前代码或官方设计文档。下文数值、地图与奖励规则均是本项目提案。

## 4. 现有流派的构筑职责

基础机制由底层规则提供，功法强化机制；毒、灼烧等状态不能要求先学核心功法才会叠加。每个流派应包含**准备、运转、终结、防护**四种职责，初入对应境界就能获得一套基础版，再通过悟道和功法层数提高效率。

| 流派 | 核心操作 | 建议完善的卡牌职责 | 明确代价 / 弱点 | NPC 使用 |
| --- | --- | --- | --- | --- |
| 金虹弃牌 | 抽牌 → 主动弃牌 → 锐势 → 单次斩击 | 至少一张可靠弃牌牌；弃牌护盾与锐势分开；终结明确消耗锐势 | 大爆发消耗积累，重复弃同一张不反复计数；无牌可弃时效果低 | 普通同宗可用基础版；精英完整使用准备到终结的顺序 |
| 叠浪回流 | 积蓄水势 → 选择保留或兑现 → 返灵 | 小额快速蓄水、低耗泄洪、大额终结各有位置 | 返灵与消耗水势绑定，回灵计数有单次结算和容量限制 | NPC 根据可用水势与手牌选择兑现，避免见浪击就清空 |
| 积焰引爆 | 维持持续灼烧 → 看时机引爆 | 低耗续燃、延长持续、引爆终结、防御性铺火 | 引爆清空已结算的存量，不能同时拿满持续与引爆收益 | NPC 避免一施加即低收益引爆；临近失效或可斩杀才兑现 |
| 毒生回春 | 毒层与时间换伤害 → 施毒联动回血 → 终结 | 保持活跃毒、防护过渡、消耗毒层的爆发 | 治疗 / 施毒 / 结算分别限次；敌方部分净化会拖慢而非抹去整套构筑 | 散修能用简版毒；精英懂维持毒与选择终结 |
| 厚土蓄势 | 本回合护盾 → 重势 → 重击或反震 | 看敌方意图决定防御量；护盾转伤与被打反震两条支路 | 本回合盾不无条件跨回合堆高；转伤消耗相应资源 | NPC 先确认敌方是否进攻，再选盾 / 转伤，避免空盾循环 |
| 连剑归锋 | 先铺剑气 → 连续剑牌 → 终结 | 补充低耗剑牌与剑系防护；多段攻击计数说明清楚 | 非剑牌打断连剑；返灵按完整连剑段触发，基础境界不额外增减伤 | 宗门剑修使用完整链；散修短链，精英有合法的三剑段 |
| 神识精筹 | 控手、减费、临时移除、保留资源 | 增加能消耗准备的输出牌；强化选牌可靠性 | 单纯抽牌不是无限净赚；减费有回合边界与最低费用规则 | NPC 仅常规控制和有限抽牌；新超量循环核心禁用 |
| 五行相生 | 有意安排五行顺序 → 返灵与抽牌 | 初级三行就能运转；完整五行是升级而非零或一 | 相生事件不可递归触发自身；错序有损失但不锁死手牌 | 具阵道的 NPC 按合法链使用常规版；玩家专属五行大循环另列 |

丹道、器道优先增强制作与道具准备；战斗时仍可配常规木 / 火、土 / 金构筑。体道、气道、燃魂可作为之后的常规独立流派扩展，但第一轮先把上述八套的核心职责和取得渠道补齐，避免同时增加大量未测试半套构筑。

NPC 最少不是“所有同道技能全带”：普通宗门为 1 套可闭合的基础构筑，精英为同一套的完整版，散修为较少主辅功法和短链。不同强度体现在准备效率、卡槽、功法层数与选择水平；不增加没有来源的隐藏伤害倍率。

## 5. 玩家专属的强力构筑池

推荐先做三套，第四套作为后续候选；均依赖**只有主修时才启用的核心功法**。辅助修炼仅给明确的普通属性，不能同时激活多套发动机。现有通用抽牌、回灵神通仍允许 NPC 正常使用，禁用的是新增的强力核心与其专属卡。

| 原创拟议流派 | 核心功法（占主修） | 专属神通职责 | 爽点 | 约束 |
| --- | --- | --- | --- | --- |
| 神识百策 | 百策归一经 | “翻卷”集中抽牌；“弃旧”移除本场冗余；“定局”消耗本回合抽牌计数输出 | 一轮连续操作十余张牌，靠整理手牌完成爆发 | 抽牌计数来自实际进入手牌，满手溢出不计；返灵按有限次数触发；专属抽牌不能零费净赚 |
| 周天回灵 | 大周天回灵经 | “引气”启动；“返照”消耗周天印返灵；“归元”把多余灵力变成终结 | 先储备、再集中回灵、打出高费终结 | 回灵消耗周天印，印不由同一返灵事件重新生成；起手准备牌本场仅一次；灵力容量仍限制 |
| 五行轮转 | 五行转轮真经 | 五行关键连接牌与“合流”终结 | 完整相生链带来多抽、多灵与持续输出 | 一次完整五行链只结算一次；额外卡带本回合标记；同一动作不能重入，不能无限复制终结 |
| 焚血逆命（后续） | 逆命焚心经 | 以真实气血换行动资源，斩杀后有限回血 | 高风险爆发，敢于压低血量 | 费用不能被护盾或减伤抵消；不致死费用 / 可致死费用明确分开；不以回血再付血构成净赚循环 |

“强力”是相对于成形的常规构筑有显著优势，而不是不受约束地卡死回合。上述触发次数、费用、伤害和启动时间均交数值模拟后定案；本文件不填未经验证的倍率。至少保留准备回合、关键牌顺序和敌方大招的决策，允许成形后出现爽快压制。

### 可用池必须显式登记

拟议内容字段示例：`Availability = Shared / PlayerOnly`、`BuildRole = Setup / Engine / Finisher / Protection`、`AcquisitionSource`。它们属于内容目录的稳定配置，不靠卡名、文案、来源字符串前缀或战力随机判断。

校验链应覆盖：普通 NPC 模板、五宗精英模板、`npc.spells` 追加、生成后的 NPC 构筑、NPC 授业、NPC 物品交易 / 战利品、内容奖励池、测试固定 NPC。真正的 `PlayerOnly` 功法 / 神通不在真实 NPC 身上装备、传授或掉落。不能只在最终 AI 计划时禁止施放，否则 NPC 面板与请教渠道仍会漏出专属核心。

玩家角色快照属于另一类使用者，不等同于真实 NPC。天机留影与联机是否允许这些新核心，需要与另一位维护者单独协调；本轮方案不擅自改其规则。

## 6. 功法与神通的对等取得渠道

推荐保留三类传承，避免所有内容都被挤进秘境：

| 内容级别 | 功法 | 神通 | 确定性保证 |
| --- | --- | --- | --- |
| 入门通用 | 城市书坊、普通 NPC 请教 | 同一书坊增加通用神通卷，NPC 请教 | 每个基础流派能买齐至少准备 / 输出 / 防护，无刷新赌关键牌 |
| 宗门常规核心 | 对应本宗藏经阁、师长授业、入门 / 晋升任务 | 同一个藏经阁 / 师长 / 任务提供配套神通 | 每个境界陈列本宗整套关键内容，宗门只供应本宗与明确通用池 |
| 非宗门常规传承 | 散修 / 特定老师、城市流派任务、常规秘境 | 同样入口的神通卷与请教 | 给散修一条付费或任务保底路，不能必须加入某宗才玩完整流派 |
| 玩家专属强力核心 | 天机阁指定传承线索 → 特殊秘境终点固定取得抄本 | 与该核心的配套卷同步给关键神通，再由目录购买 / 任务补齐非关键升级牌 | 核心和运转关键神通不分开随机，不需要“抽到功法后再等十年找神通” |

取得抄本与真正修习分开：奖励给抄本及关键神通卷，修习仍由已有后端报价与学会动作完成。若决定神通卷可以直接领悟，界面必须明说两者差异。不要奖励了抄本却日志写“已修炼功法”。

统一“传承目录”展示功法与神通，每条有境界、流派、是否已获 / 已学 / 已装备、效果数值、确定来源、前往入口。构筑页面列出缺哪几项以及最短可达取得路。进度是“已满足构筑职责 / 所需职责”，不以未学卡发亮假装拥有。

书坊 / 藏经阁 / 师长仍承担常规成形；特殊秘境承担跨境界的重要奖励。固定关键奖励不会把普通奖励全部改成固定：沿途仍可三选一临时牌、临时遗物和路线，形成每次不同的探索打法。

## 7. 特殊秘境入口、周期和对应境界

硬约束按**大境界**判断，不按小境界简单比较 `>=`：炼气角色只能进入炼气特殊秘境，筑基角色不能返回炼气场。已经入场的 run 冻结境界与配置版本；跑局期间不提供突破、换装等绕开限制的动作。

建议在现有地图点上加“特殊秘境入口”，不新增海域大地图。下表地点与窗口是拟议分配，周期是用户要求：

| 大境界 | 周期（已要求） | 建议入口地图点 | 建议开放窗口（待确认） | 界面展示 |
| --- | --- | --- | --- | --- |
| 炼气 | 10 年 | 东石谷古迹 | 2 年 | 当前开放 / 入道第 N 年再开、至少同境 |
| 筑基 | 20 年 | 无尽海潮汐遗府 | 3 年 | 对应境界、开放起止年、路线风险 |
| 金丹 | 50 年 | 天魔眼外层 | 5 年 | 目标传承、首通附魔机会是否可领 |
| 元婴 | 100 年 | 无尽海沉星宫 | 8 年 | 下次窗口、剩余时间、首领机制 |
| 化神 | 200 年 | 天魔眼深层 | 10 年 | 同上 |

推荐以游戏世界年 / 入道年统一锚点计算周期，不用 NPC 年龄或玩家本次旅行出发年作锚点；具体首个开启年需要最终确认。线索可随时购入，但购买前显示**最早可进入窗口、境界严格匹配、是否来得及赶路、错过后下一周期**。不允许卖当前境界永远不能再进入的旧境线索。

线索是永久掌握的知识，窗口关闭只让本次入口失效，不抹掉已付费的传承线索。未通关退出则当前 site 消失；该次窗口不能重新生成同一 site，无限失败刷房间不可行；到下一个合法窗口可用已知线索获得新 site。其是否额外收取小额重新定位费是价格项，暂不添加。

进入前检查有效窗口；**成功入场后允许完成本次探索**，不在内部每回合因为世界窗口关闭强制逐客。既有内部冻结日历 / 离境结算耗时继续保留。离境跨月、跨年、兽潮暂停时仍通过真实的剩余工作继续入口恢复，不能为新秘境另加一套世界时钟。

### 突破后错过旧核心的两个选择

推荐：当前大境界秘境在买线索时可选择“当前核心”或“尚未获得的旧核心”；实际入口和怪物始终是当前大境界难度。这样满足禁止进入旧秘境，同时让快速突破者能补齐旧流派。**这只是建议，用户尚未批准。**

严格版：各境只出各境的核心，错过不可补选。缺点是新手容易在不知情时永久失去某套构筑，需要在突破界面醒目提醒。若选择严格版，常规流派仍必须能通关后续秘境，不允许要求已经错过的专属核心才可取得下一阶核心。

## 8. 每境首通附魔（主建议）与删牌（备选）

用户后续提出附魔选定卡牌作为删打防的替代候选，尚未批准采用附魔取代删牌。我们推荐附魔：它能让玩家挑选自己的启动 / 防御 / 终结牌，局部调节可靠性，比永久削薄整个牌堆更容易控制强度。但附魔也会提高抽牌、回灵发动机的可靠性，不能视作天然安全。**本文奖励方式与附魔限制均为未批准建议，实际游戏没有启用。**

| 奖励方式 | 收益 | 风险 | 推荐定位 |
| --- | --- | --- | --- |
| 选定单牌附魔 | 可控起手、留住关键牌；偏好基础牌的玩家也有提升 | 起手发动机可能大幅提升一回合爆发；同类型副本误应用容易翻倍 | 主建议，配合实例 ID、白名单和生效上限 |
| 永久删一攻一防 | 牌组更薄、所有核心更容易抽到 | 对全部流派产生永久乘数；快速突破错过后难补；全删会破坏不完整构筑 | 保留作互斥备选，建议最多删 4 对、至少留 1 攻 1 防；不与每境附魔同时发 |

### 首通与附魔机会

- 每世每个大境界首次完成任意特殊秘境的首领和奖励结算，给 **1 份附魔机会**；五境全部首通最多 5 份。机会可以先保存，离境后在角色构筑界面选一张永久牌附魔。
- 以 `SpecialDungeonFirstClearByMajorRealm` 和绑定该大境界的唯一奖励记录去重；同境不同流派、不同 site、不同开放窗口都不能再领首通附魔。
- 错过旧境首通不自动补发；当前境补选旧功法也只触发当前境一次奖励。重开一世清本世附魔机会与附魔状态，不带入账号天赋传承。
- 单张**永久牌实例**只能有一个附魔；不能重复付机会给同一牌叠两层，也不对同名所有副本一起生效。基础五攻五防的每一张均可选；不是只允许最强核心牌参与。
- 不限定全部机会立即用满；建议允许在场外重新选择已附魔牌的“启用”配置，不改变牌所属附魔、不退还机会。战斗或秘境内禁止切换启用配置。

### 第一轮的附魔效果与建议上限

建议先只开放两种明确的规则效果，不第一轮加减费 / 返灵 / 伤害倍增：

| 附魔 | 准确含义 | 明确不包含的效果 |
| --- | --- | --- |
| 固有 | 当前已装备、启用附魔的这一副本在**本场第一手**优先入手，仍占首手槽；首手原抽 5 张，固有 1 张就再正常抽 4 张 | 不额外增加手牌，不每回合上手，不免耗，不自动施放，不让两张同名副本一起固有 |
| 保留 | 回合末自动弃牌时，将**未打出的、仍在手中的这一副本**留到下一回合；仍占手牌容量 | 已打出进入弃牌的牌不回手；不免费用、不取消冷却；换念主动弃牌与忘机移除仍按动作结算 |

起步建议：**同场最多启用 3 张附魔牌，固有总数最多 1 张，回合末保留最多 2 张；既有手牌上限 8 不增加。** 这些是后续模拟需要验证的候选上限，不是现有规则或用户已批准数值。五次奖励可以为多种牌准备附魔，三张生效上限让换构筑仍有选择，而不是五份全部叠进最强起手。固有先保守为 1 张，与本轮数值分析建议一致；增加到 2 张需先测起手发动机组合。

保留牌不进入回合末弃牌钩子，因此不产生金虹弃牌的弃牌计数 / 护盾 / 锐势。下一回合正常抽牌按现有容量截断；被保留的牌占容量，但不视为“本回合新抽”计入神识发动机。施放后离手、耗费和冷却仍沿用原神通结算。强制弃牌、移除、死亡、战斗结束的优先级须明确，不能以保留标签挡掉所有其他动作。

抽牌 / 回灵专属发动机建议第一轮不能选固有；普通低效准备牌、基础普攻防御、终结牌可选，构筑仍有启动思考。以后允许专属发动机附魔时再为 `LoopEngine` / `DrawEngine` / `ManaEngine` 设显式白名单，并约束这类牌的附魔生效总数，不能把一轮净赚闭环都设成首手。原有发动机的每回合触发上限、容量限制继续有效，不靠怪物强制禁牌修补无限循环。

### 工程方向：先建立永久实例身份，再应用覆盖

现有 `Card::uid` 是临时战斗牌 UID：同一神通两个副本按组牌位置生成，换携带顺序可能改变；秘境 UID 又是另一套序号。因此不能将 `card-3` 当作永久附魔归属，也不能存成 `map<SpellId, Enchantment>` 导致整类牌附魔。

推荐为玩家永久可带副本登记稳定 `CardInstanceId`，与受控 `SpellId` 和副本位置关联：基础攻、防各五个实例；一门普通神通的两个副本各有不同实例。取得 / 初始化时在后端分配一次，场外卸装保留实例与附魔，重新装备同一副本恢复；未来内容改版减少副本数时需要显式迁移。永久 ID 不能来自客户端字符串拼接，必须查询该角色拥有的实例目录并校验归属。

`SpellDef` 保持基础费用、伤害与能力定义不可变；实例附魔保存类型与启用选择。组牌时为临时 `Card` 复制 `SourceInstanceId` 与冻结的能力覆盖，秘境携入牌复用该来源。沿途新增临时牌没有永久来源，不继承同名附魔；法宝主动能力独立牌堆 / 冷却规则，首轮不纳入卡牌附魔。

能力标签以 `enum class` / 白名单登记（例如 `Innate`、`Retain`），预览、组牌、抽牌、回合末分区与真实结算委托同一权威规则。不在前端按名称“包含固有”来决定效果。开局先查启用总数、固有总数和卡归属，再建立确定起手；已冻结战斗不因玩家场外目录变更重新算一次。

新增持久项覆盖永久实例目录、实例附魔、启用选择、已领首通 / 未用机会；codec、形状 / 领域校验、旧档默认值、往返测试同步。已有档默认无附魔、基础攻防仍各五，不因登录悄悄补发历史首通。拒绝非法实例、未知标签、第二层附魔、超过上限、无机会、战斗中操作时不扣机会也不改资源。真实领取与施加各自定义重复请求去重，保存失败不能诱导再次支付。

普通 NPC / 精英 NPC 不领取玩家首通附魔。若后续希望极少数剧情敌人有固有 / 保留，作为其显式受控模板独立评审，不能由玩家附魔状态自动传过去。

### 删一对基础攻防（若改选，取代附魔奖励）

删牌备选建议：每世、每个大境界第一次完成**任意一个特殊秘境的首领与固定奖励结算**时，前四次有效首通各永久减一张普通攻击与一张普通防御，且不再发这一境的附魔机会；**最多删 4 对，至少保留 1 攻 1 防**。第五次不同境界首通改给另一份固定灵石 / 非附魔的传承升级奖励，具体奖励量待定。不按流派线索、site 或开放次数分别发删牌，避免刷不同功法反复减牌。

| 已完成不同大境界的首通数 | 普攻张数 | 防御张数 |
| --- | --- | --- |
| 0 | 5 | 5 |
| 1 | 4 | 4 |
| 2 | 3 | 3 |
| 3 | 2 | 2 |
| 4 | 1 | 1 |
| 5 | 1 | 1（改给另一份首通奖励，不再删牌） |

这只是拟议永久奖励；当前游戏仍是固定五攻五防。记录 `SpecialDungeonFirstClearByMajorRealm`，删牌对数由有效的五境首通集合推导后截断到最多 4 对，或保存后交叉校验，不能允许负数或低于 1 / 1。各境界“打通”应把**固定抄本 / 配套卷 / 首通标记 / 删牌结果（第五次为替代奖励）**放在同一次真实结算里；重复点击、读档恢复、奖励回应丢失都不得重复删牌。

早期讨论曾把五境首通对应到 0 攻 0 防；该条件只保留为隔离数值对照，不作为建议上线规则。数值报告已比较 5 / 5、2 / 2、1 / 1、0 / 0，发现全删提高核心密度，也可能让没有伤害终结的辅助构筑彻底失去攻击能力。因此备选建议保留 1 / 1 下限，不能把全删样本当作已获批准玩法。

错过炼气首通后直接筑基，不补发炼气删牌。即使筑基秘境选旧功法，其删牌仍只归筑基首通，最多一次。已经完成某境首通后再通同境不同传承，只给该传承和重复奖励。重开一世回到五攻五防，不把缩减带进账号永久传承。

影响范围必须包含普通战斗、秘境入场、构筑预览、牌堆完整性校验和保存恢复。NPC 不通过这套玩家首通删牌；NPC 普攻 / 防御数量作为普通 / 精英模板的独立数值项评审，不能读玩家的首通进度。

通关前后应提示构筑职责，特殊奖励提供配套的实际可学神通；保留 1 / 1 下限避免辅助构筑失去全部基础攻防。规则不替玩家自动装备或秘密塞回基础牌。

## 9. 特殊秘境的路线与怪物机制

推荐复用现有三列路线与每境 9～13 层；第一轮不新增多目标战斗，先用单个敌人的阶段、意图与状态做特色。多怪同屏会涉及目标选择、逐怪状态和存档，需要另开实现范围。

### 路线结构

- 起点两场普通怪教学，再提供普通 / 精英分岔；精英支路多给一次临时遗物选择，安全路有事件 / 营地。
- 至少保证一个中途营地和首领前营地。营地在治疗、临时强化、临时移除中取一项。
- 秘境入口直接展示首领机制摘要；首领不是跑到最后才发现恰好免疫整套构筑。
- 普通节点给临时神通三选一，可跳过；精英给机制相关遗物。特殊秘境配套核心的“试用版”在入场后作为临时传承获得，允许先玩后拿，但不带出、更不赋给 NPC。
- 怪物候选提前显示擅长机制和强招预告。选路径不是在三个同名妖兽之间选位置。

### 普通与精英怪候选

| 原创敌人 | 意图 / 行动循环 | 考察能力 | 可行应对，避免硬封杀 |
| --- | --- | --- | --- |
| 潮壳蟹（普通） | 小攻 → 短时护壳 → 多段攻；护壳回合结束破壳露弱 | 把爆发放对回合，或用持续伤害铺场 | 护壳减直伤但不免疫；所有构筑都有非永久的输出窗口 |
| 引焰蛾（普通） | 铺灼烧 → 弱攻 → 预告引爆；引爆后熄焰休整 | 防持续伤害与时机，控制 / 斩杀 / 护盾准备 | 只清自己引爆资源，不清玩家所有状态；引爆可被明确防护降低 |
| 拾骨傀儡（普通） | 一次强护甲 → 攻击 → 维护低攻；护甲耗尽进入虚弱一轮 | 连击与贯穿、持续伤害、蓄力 | 护甲有有限量；不用“金 / 剑无效”的类别免疫 |
| 忘念魇（普通） | 一张短期淤滞牌 → 小攻 → 清障并休整 | 控手与临时移除 | 障碍有自动消失条件，负面牌数量上限明确，不永久污染玩家牌库 |
| 贪灵兽（精英） | 首回合准备；连续回灵触发有限蓄势，第三轮释放可防大招 | 玩家决定多回灵爆发还是省牌防御 | 只在超过阈值后有限触发，显示本轮累计；压制上限和休整轮保证循环牌仍可赢 |
| 藏锋剑卫（精英） | 蓄剑 → 多段攻 → 收剑露隙 | 本回合防御与连续小伤害，应对周期 | 不因出剑牌就永久惩罚玩家；攻击前完整显示段数与伤害 |
| 泥身尸王（精英） | 少量净化 → 吸血攻 → 蓄力 → 重击 | 毒 / 火维持与补层，所有流派的打断 / 防护 | 净化有冷却，最多削部分层数，绝不每回合清光毒火 |

### 五境首领候选

| 对应境界 | 原创首领 | 阶段规则 | 玩法目的 |
| --- | --- | --- | --- |
| 炼气 | 古阵守门灵 | 护阵 → 预告重击 → 露隙；足量伤害可提前打断一次重击 | 学会看意图与准备，基础构筑即可通关 |
| 筑基 | 潮汐龙骸 | 涨潮期小攻并蓄潮，退潮期强攻后露弱；每次转换公开 | 允许蓄势、持续和爆发各有优势窗口 |
| 金丹 | 天魔镜主 | 初段复制上一轮一种普通状态的弱化版本；中段切换为护体 / 输出交替 | 检查卡牌顺序；不复制玩家专属功法、伤害或无限发动机 |
| 元婴 | 沉星镇守者 | 有限护甲阶段 → 能被打断的聚星 → 多段强攻 → 空窗 | 要求可靠防护与稳定输出，保留毒火慢杀路线 |
| 化神 | 三劫魔相 | 精筹、御守、劫火三个阶段按预告循环；超过出牌阈值增加**下轮有限压力**，不立刻强制结束回合 | 对强力流派提出调节节奏的考验，而非禁止抽牌回灵 |

怪物的数值由统一怪物配置、既有 `战力 × 0.3 + 18` 伤害基数和后续数值模拟确定。本表只定义状态机。新怪物不得拥有对某大道完全免疫、无法看见的固定减伤、无上限永久成长、非预告即死或每回合清光全部持续伤害。

意图最少包含动作名、直伤 / 段数、护盾、施加状态、资源消耗、变阶段条件、预计实际掉血（单列说明当前护盾 / 减伤）。执行前冻结选择，玩家出牌导致状态变化时更新同一预测规则；不能查询时重新随机行动，也不能意图为零却结算出高伤。

## 10. 奖励、天机线索与高阶材料的承接

天机阁建议按“境界 → 流派 → 目标功法”分类。每条线索直接列目标核心、配套神通、最早窗口、对应入口、重复已学替代奖励、完整费用；购买只是确定目标传承，不能改随机种子重新刷更好的核心。线索价格按境界与目标目录由后端统一配置，报价和扣费共用规则，具体数额交经济模型后确定。

特殊秘境奖励分两层：

1. **该传承首次取得**：固定目标核心抄本与最小可运转的关键神通卷；不让玩家在核心和配套关键牌之间只能二选一。另有一份明确的基础灵石奖励。按同境首通条件额外给一份附魔机会；若最终选择删牌备选，前四次以减一攻一防取代附魔，第五次改给另一份固定非附魔首通奖励，至少保留 1 / 1。
2. **同传承重复通关 / 同境后续窗口**：有限灵石与同级材料奖励；未学的升级神通可定向选一；全已学时直接显示兜底。没有第二份同境首通附魔机会，也没有重复删牌 / 永久功法无限叠层。每次 site 仍最多结算一次。

保留材料用途，不能让高阶炼制只能等两百年：

| 既有渠道 | 改版后的职责 | 保底要求 |
| --- | --- | --- |
| 普通坊市 | 一、二阶炼丹 / 炼器材料常驻交易 | 仍能一键补齐当地可售低阶配方，不迁入特殊秘境 |
| 宗门材料区 / 后山 | 本宗药材与器材的确定性来源 | 各常规流派突破与制作需要的材料有可追踪路径 |
| 灵田 | 玩家已取得的可种药材长期生产 | 妖丹等非植物不纳入；小绿瓶 / 配给仍沿用自己的成本与生长规则 |
| 兽潮坊市 | 高阶限量材料的重要交易场所 | 不卖无效果法器，不混入宗门贡献物；数量和折扣仍用兽潮现有规则 |
| 常规野外秘境 | 高阶材料与灵石的主要探索渠道，普通传承为额外选择 | 增加按材料类型可追踪的入口 / 生境奖励，不能删除天机材料情报后只剩纯随机 |
| 无尽海 / 天魔眼特殊秘境 | 传承为主，高阶材料为辅助 | 不替代常规材料保证；窗口长等待不成为炼制唯一门槛 |

由原天机材料线索转移的定向材料功能，推荐作为**常规秘境的材料委托**：从任务面板选择真实配方所缺材料，指向当期可进入、对应材料最低需求境界的普通野外副本；通关保底该材料。它不是又加一个高周期特殊入口，也不再占天机阁“功法线索”的定位。价格与周期需要经济评审，但不能在旧功能删除后才补救。

开放特殊机制前，先为每份高阶配方做来源覆盖表：材料 ID、最早用途境界、植物 / 妖丹 / 器材、生境、常规确定渠道、供给频次。若某低境界必需配方的材料只有化神窗口才能拿，阻止发布。

## 11. 退出、失败与首通安全

- 未通关主动退出：当前秘境 site 消失，沿途临时神通 / 遗物不能带出；已可兑现物资继续沿用既有结算，不隐式清角色全部背包。
- 非致命战败撤离与真正死亡不同；当前 `settleRun(lost)` 有损失物资的撤离路径。新特殊秘境不自行发明“死后还能保留奖励”的第四种处理，按真实战斗来源的死亡 / 回档既有规则接回。
- 真正死亡：仍进入现有死亡 / 重开 / 回档选择。寿尽仍按原人生结算，不被秘境覆盖。
- 不通关不给永久核心，不发同境首通附魔机会或备选删牌；首通奖励只在合法首领胜利和真实结算之后产生。
- 读档不能改变已经冻结的目标、路线、首领机制或奖励；掉线 / 重复回应不能两次发核心或扣线索费。
- 入口用稳定 ID，境界和窗口由后端判断；伪造低境 site、过期报价、已领首通、非法奖励 ID 必须明确拒绝并保持资源、RNG 与进度不变。

## 12. 可维护的实施分层与默认关闭

推荐后续按三个独立变更推进，避免一份提交同时改全战斗、全秘境与全经济：

1. **内容与取得目录**：统一构筑职责、常规功法 / 神通源、玩家专属标志、NPC 过滤与常规模板 AI。现有玩法保持可用。
2. **特殊秘境状态机与附魔身份**：周期 / 窗口 / 同境进入、怪物意图、冻结目标、首通去重、永久卡实例与附魔、codec / 校验。以默认关闭闸门隔离，不挂世界时钟、不生成入口、不改 NPC 牌池；未就绪时即使请求打开也拒绝。
3. **评审后启用专属内容与奖励**：定向核心、配套神通、材料来源接替、经济预算。只有真实冒烟与平衡样本满足发布条件才开闸。

拟议职责落点：

| 模块 | 新职责 |
| --- | --- |
| content | `BuildDefinition`、内容可用池、怪物阶段定义、稳定传承与文本 ID；显示名不参与规则判断 |
| progression | 核心功法触发、构筑职责查询、永久卡实例 / 附魔拥有状态、同境首通奖励状态；删牌查询仅在改选备选时加入 |
| combat | 共用效果结算、实例附魔覆盖的起手 / 保留规则、有限触发计数、NPC 常规构筑决策、怪物阶段 / 意图 / 真实执行 |
| exploration | 周期与窗口、线索 / 入口 / 路线报价和操作、完成与退出编排、合法首通结算请求 |
| social / crafting | NPC 知识可用池、常驻传承采购、常规材料委托与来源覆盖 |

新 C++ 命名遵循 PascalCase / `mf`，实现不继续堆入 `api.cpp` / `app.mjs`，新增源文件同步 CMake 和静态 VS 工程。关闭时不能偷偷发附魔、给玩家删牌、改神通目录或增加 NPC 行动；旧正常秘境不因一条 special 字段导致无法运行。

## 13. 后续平衡与验收计划（新机制尚未执行）

先对八套常规构筑建立同境、同功法层数、同资源预算、同基础牌数和装备的固定种子样本。记录胜率、有效回合、平均受伤、首回合爆发、启动卡缺失概率、毒火真实结算占比、最高抽牌 / 回灵 / 出牌次数；配上基础策略、知道意图的正常策略，不能用全知穷举 AI 代替真人体验。

常规 NPC 与精英模板分别测，报告“NPC 牌池完整但 AI 没打出连招”的失败，不把它误认为流派弱。玩家专属构筑单列目标：成形后强于同成本普通流派，但准备与未成形期间仍有风险，能应对各 Boss 而不要求某一元素才过关。

每个首领至少由持续伤害、直伤爆发、防御蓄势、抽牌回灵四类构筑各跑一组；任何一类遭机制硬封杀先改机制，再考虑提高数值。本轮数值专家已另外输出 [战斗基线与构筑分析](2026-10-14-combat-balance-analysis.md)，其中基础攻防缩减对照支持先谨慎控制起手可靠性，但附魔机制本身尚未实施或模拟，不能宣称本文件附魔上限已经平衡完成。

定向边界：对应境界允许 / 前后境拒绝、窗口首末日、突破后旧境拒绝、线索预购后到期、不同 site 同境首通去重、附魔机会不重复、同名副本只有所选实例生效、固有占首手槽、保留未打出手牌且不触发弃牌收益、主动弃牌 / 移除优先级、满手抽牌限制、循环发动机禁用 / 限量、非法附魔拒绝、旧档默认无附魔。删牌备选另测最多删 4 对、第五次只发替代奖励、始终不低于 1 / 1、错过旧境不补删牌。共同测重复已学奖励、读档继续、失败原子性、怪物阶段切换的预览与结算一致。

真实浏览器冒烟：定位购买 → 赶路中断恢复 → 同境入场 → 节点 / 战斗 / 首领 → 奖励 → 离境时间 / 兽潮中断 → 场外指定副本附魔 → 普通战斗固有 / 保留。若改选删牌，再替换最后流程为普通牌堆缩减。覆盖重复点击、过期响应、失败恢复与桌面窄屏，记录响应耗时。测试用临时账号、目录、端口，不改玩家正在玩的档。

## 14. 需要最终确定的规则

1. 开放窗口是否采用 2 / 3 / 5 / 8 / 10 年；首个开年与计时锚点采用哪个世界年。
2. 是否允许当前境界秘境补选旧核心功法。无论选择哪版，都不允许进入旧境秘境，不按补选次数追加首通附魔机会或备选删牌。
3. 最终奖励采用附魔，还是删一对攻防。本文推荐每世每境首通一份附魔机会，单牌单附魔、3 张同场启用、1 固有 / 2 保留上限作为待模拟候选；是否必须指定试炼才发首通也待确认。
4. 强力核心从炼气提供弱化入门版，还是筑基后开放完整发动机。本方案推荐炼气有可运转的普通构筑，筑基起开放第一套强力核心，较高境给第二 / 第三套。
5. 窗口内未通关退出后，是当次窗口完全不能重试，还是允许购买新线索尝试别的传承。本文推荐同一 site 消失且同传承本窗不再生成；其他传承可入新 site，不重复发首通奖励。
6. 常规材料委托的刷新频次、价格、同境保底数量；应与天机转型同批上线，防止高阶材料来源断档。

确认这些规则后再写实现计划；本轮不把建议机制开放给现有玩家。
