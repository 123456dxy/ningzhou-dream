# 2026.10.12-desktop-refactor.1 版本说明

本版基于 main 的 `fa43732`，提交到 `codex/backend-desktop-ui`。按职责整理后端与桌面 UI；移动版与天机大比业务实现保持原样。增加显式本地电脑端启动模式，不传 `--local` 时仍使用公网鉴权。玩家现有存档字段和版本不变，炼丹炼器的配方、成功率、时间、消耗、产出不调整。

## 本次更新

- 后端按 11 个职责目录分类，词表集中稳定 ID 与显示文字，序列化、视图、路由策略分别归档；保留公共头兼容入口。
- 提供 `visual-studio/ningzhou.sln` 和相对路径项目，目录分组与本地 CMake 解决方案一致；附模块设计与 C++/HTTP API 索引。
- 桌面新增行囊与面板、独立工坊、任务入口。任务收纳城市、宗门、悬赏和支线；坊市保留交易。行囊可按物品类型和品阶筛选，点开具体丹药详情后查看真实效果、丹毒和数量，再选择服用。
- 详细属性、中文天赋、声望说明归入人物面板，人物侧栏显示资质、悟性、福缘；成就显示达成状态并限制进度条，不再重复人物档案。
- 岁月行卷初始 360px，可上下拖动并记住高度；五项日常计划压缩为单选控件。修复纪事分类无响应，保留旧导航链接。
- 战斗自然回灵显示“恢复到 N 点”，增量回灵神通仍显示增加量；剑意兼容字段不参与独立境界增减伤。
- 炼丹、炼器及进行中工作显示实际效果和数值；整批炼丹校验当前份数的材料、灵石和耐久。
- 一键补料按所选配方乘份数，仅购买缺口，展示本地可购性和预计灵石。整单在副本中执行，缺钱、不可售、库存上限或失效报价均不部分扣费/买入。炼器多份备料仍逐件开炉。
- 自炼法器分解返还原配料总数的 50%，不足一份向下取整，手续费每阶 5 灵石。确认前展示材料和费用。新法器把配料写入既有 flags；旧档仅回收能从旧名称确认的主材 2 份并明确提示估算，无法确认时保留法器供出售。
- 重开前预览本世未领取成就增加的天赋点；成功建号才结算传承，非法方案、重复成就和传承写入失败均不刷点、不丢当前人生。
- 药谷奖励发放真正可使用的具体草药，事件纪事记实际变化；修炼求援文案与当前行动相符。
- 新增 12 张透明 NPC 立绘，30.14 MB 原图压为 2.08 MB WebP；按稳定人物身份选图，角色卡与战斗一致，不消费随机数。
- 坊市与工坊显示完整丹药能力，行囊保留当前真实服用收益。品阶默认一阶并记忆选择，书坊与突破物品合并为坊市分类；天机阁情报默认三阶并支持类型、品阶与搜索共同筛选。
- 修复 Windows 中文安装路径及资源子目录读取，按真实路径检查静态根目录边界；新增本地启动入口并隔离多人存储依赖。

按用户最新要求，尚未补齐的中文函数注释延期；已经完成的注释保留。用户自行修改的一处文字保留，未作专项核对。
