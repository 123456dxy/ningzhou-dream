## 电脑端 UI 的实际变化

朋友并非仅修改手机界面。原桌面入口也包含以下变化：

- app.mjs 接入登录与天机大比导航、提醒、浏览器历史和按键保护。
- 新增侧栏突破按钮、突出可突破状态和不足条件，自动滚动到突破区域。
- index.html 接入登录、排行榜、反馈、天机大比和移动样式；存档说明改为云端、多人独立存档。
- enhance.css 添加登录遮罩与突破按钮样式。
- 地图和人物资源切换为 WebP，资源总量明显缩小；既有图片引用随之更新。
- 另外新增独立 web/v2 手机界面、底部导航、地图/行囊/社交等模块及其验收脚本。

## 后续协作方式

- `main` 保存已经集成、可运行的版本。
- 我们负责后端规则及原版桌面 UI；当前工作分支名明确这一职责。
- 朋友负责 `web/v2`、移动适配与联机。但联机涉及 `web_main.cpp`、transport、Session 和 persistence，仍需要共同核对契约。
- 提交应按一次可审查的任务组织，完成后通过 PR 合入 main。分支不是每天生成一份完整游戏副本。
- 公共 JSON 字段、存档 schema、登录接口、留影规则的修改需要同时检查两个前端；词表显示文字变化不应改变这些标识。
