# 独立斗法试炼场

本入口用于在八个现有流派、五个大境界和不同对手之间反复试战。角色只存在于独立服务内存；不登录账号，不加载或修改人生存档，不发放奖励、不推进兽潮或世界时间。每次开始按选择重新建立角色和真实牌堆，同一构筑、对手与种子可复现同一开局。

## 构建和启动

在 `visual-studio/ningzhou.sln` 中构建 `ningzhou_battle_lab`，配置为 Release / x64。CMake 同名目标和静态 VS 项目使用同一份当前工作区源码。新增文件后先运行 `tools/generate-vs-projects.py` 同步工程。

```powershell
.\build-vs-share\Release\ningzhou_battle_lab.exe --port 8111 --web .\web
```

浏览器打开 `http://127.0.0.1:8111/battle-lab.html`。该程序固定监听本机地址，不替代正常游戏服务。现有游戏与试炼场互不共享会话。

## 怎么测试

选择流派、境界和对手后开始。推荐先在筑基试套路，再选择金丹或更高境界检查完整连招。角色的主辅修、悟道与神通按统一试验预算分配，低境界不绕过牌槽或境界限制，缺失组件会在构筑详情中列出。预览、发牌、出牌、敌方规划、持续伤害与胜负均调用正式规则引擎。

手牌显示实际费用和当前效果；敌方意图显示本回合预计伤害。毒与灼烧还可能在后续回合结算，不能把当前意图为零理解为未来没有伤害。结束回合前查看护盾、状态和“下回合恢复到”的灵力值。忘机咒需选择本场移除目标。

默认每次点击开始或重新开局时生成新种子；勾选“固定种子”可输入0至4294967295之间的整数，复现同一开局。胜负后的“同种子再试”沿用该局种子，方便比较打法；“再来一局”使用新种子。只刷新页面或查看状态不会重开、换种子或推进牌堆。正式人生的开局和弃牌重洗始终推进存档中的RNG，不在每次开战时恢复到试炼默认种子。

毒不再按三回合自然消失，而是在本场持续至净化或战斗结束。筑基起木毒模板携带滋毒诀：实际2灵力，使已有毒层增加50%（新增层向上取整、总量最多99层），每跳毒伤按实际增层比例复制，不附带直伤或叠毒回血；使用后隔一个完整自身回合才能再次使用。无毒和满层时手牌会禁用并解释原因。普通引毒咒改为借毒回春：实际2灵力，按敌方活跃毒层治疗自身，每层为本境界伤害基数4%（合计四舍五入），本术不超过自身最大气血12%（向下取整），不超过缺血、不清毒、不吃治疗与输出乘区；独立第三牌回春另算。无毒、满血或本术治疗为0时禁用，使用后隔两个完整自身回合才能再次使用。

五行剑保留剑气、相生回灵和补牌，取消与普通剑修同轮连剑增伤的叠乘；五行剑诀每层功法对每层相生强化的附加收益由4%调整为2%。五层主修叠满五层强化时，额外收益倍率为1.5，基础伤害、返灵和抽牌不受此倍率放大。卡面与敌方意图均由正式规则预演。

胜负后保留战报，但不继续世界进度。自动试玩只能说明对应策略、种子和试验预算下的结果，不等同于玩家最优打法或整个游戏的胜率。

## 接口与维护边界

独立服务提供 `/api/lab/config`、`/api/lab/state`、`/api/lab/start` 和 `/api/lab/turn`。只读查询不改变 RNG 或局数；动作携带版本号，重复或过期请求被拒绝，不重复出牌。开始和出牌先在副本核算，成功后整体提交。

领域场景在 `src/core/combat/battle_lab.*`，JSON 编码和请求校验在 `src/core/interface/battle_lab_api.*`，服务组装在 `src/battle_lab_main.cpp`，独立桌面页面为 `web/battle-lab.*`。正常账号服务、手机页面、天机大比实现不参与此次入口拆分。

本轮参数、构筑变化和实际验证见 [流派平衡记录](reviews/2026-10-15-development-validation.md)。

## 初始流派与完整传承

选项卡支持初始/完整两种模板，低境界仍遵守真实神通槽、主辅修与悟道预算，不以完整传承绕过资格。六宗包含玄道宗五行归剑，五剑顺序为土→金→水→木→火。相生与独立五剑进度可跨回合，气/神/普通攻防等非五行牌不打断；错序有效五行仍重开。`elementalSwordSequence`与普通`swordSequence`独立，手牌`elementalGenerationReady`由真实效果预览提供。完整模板具有更多经营组件，并不保证面对所有敌人都优于初始模板。正常世界长期存在传承导师，可在道法完整传承面板定位并按真实请教规则逐项学习。

伤害分开显示打出伤害与实际气血伤害，差值可能来自减伤与护盾；忘机咒只选择并移除一个实例UID，同名副本保留。本地实验页不进入正式游戏菜单；正式Web资源和发布包排除三个battle-lab页面文件，实验exe另用battle-lab-web资源。

2026-10-15已有独立测试预览：`http://127.0.0.1:8112/battle-lab.html`。该地址仅当前本机服务有效；旧8111服务保留，避免打断正在进行的测试。

## 与真正新角色的区别

试炼中的“初始流派”是已获得一套功法与悟道的构筑示例，不能当作刚建号的强度。真正新角色仍只有吐纳功1层、无辅修或悟道，默认携带金芒刺、焰火诀、水灵盾、聚气；原入门已知神通保留可换装。真实建角对劫修的策略、同境/越一小境与24轮失败记录见[新手斗法](STARTER_COMBAT.md)。旧角色不自动换装。

火道本场成长、3费噬焰回生和妖兽分段动作纳入本轮实际试验。六宗普通/完整的均匀对兽矩阵、组内互打表及瑞士排名分别见[跨组结果](BATTLE_BALANCE_RESULTS_2026_10_15.md)、[组内结果](BATTLE_MIRROR_RESULTS_2026_10_15.md)；表中的机器人胜率不能视为真人胜率。摄魂术绕过全部护盾但仍受减伤，五行剑没有隐藏穿盾。
