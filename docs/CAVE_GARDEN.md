# 洞府灵田与永久小绿瓶

本页对应灵田规则版本2，取代原99苗、按格储备和按日收费规则。完整冻结数值及周期验收表见 [小绿瓶改版约定](GREEN_BOTTLE_V2.md)。

## 管理与后台成长

洞府沿用 `Player.cave` 的合法地图地点ID，人在该地点即满足 `cultivate::atCave`。洞府页随时可读；播种、收获、清理、小绿瓶升级和专属秘境进入要求人在洞府，且没有工作、斗法、抉择、秘境或人生结束。洞府档位解锁3/5/8格，状态固定保存八格。

每格只种一种草药，最多12份种苗；追加种植建立零进度独立批次，不继承旧批次进度。播种扣已持有药材，成熟每份收3份。妖丹由稳定内容ID排除。收获只移除成熟批次，未熟批次保留；清理直接放弃种苗。

`crafting/garden_rules.h` 是成长和升级数值唯一配置。自然日增按洞府档位为20/40/60点；持有小绿瓶者再加当前永久瓶阶的0/45/85/150/250/420/700点。六品成熟阈值依次为18000、45000、112500、281250、703125、1757812点。

```text
总日增 = 洞府自然日增 + 永久瓶阶附加日增
预计成熟日 = 向上取整(max(0,成熟阈值-当前批次进度) / 总日增)
```

成长不读取灵气配给、不每日扣费，也不需要停留洞府。`mfGardenDayTick` 接真实世界日，`LastGrowthDay` 保证同日幂等；生命结束后停止生长。秘境中原有世界日历暂停，探索累计天数在离境时结算，因此后台成长也在这些真实日结算时发生。成长封顶后等待手动收获，不自动入库或复种。预览直接按共享阈值取整，不逐日模拟整季。

## 永久小绿瓶与专属灵材

只有 `greenBottle` 天赋持有者拥有0至6阶永久瓶阶。每次只升一级，升至1至6阶的灵石分别为2000/5000/8000/10000/20000/40000；升4/5/6阶还需对应专属灵材50/100/200份。`mfQuoteGreenBottleUpgrade` 与真实升级共用资格、费用和材料缺量，`expectedGrade` 阻断重复点击或过期报价跨级消费。

三类专属材料及秘境定义在 `content/green_bottle_content.h/.cpp`，采用独立白名单ID。瓶阶3/4/5分别解锁4/5/6阶灵材秘境，满6阶仍保留6阶入口。无额外人物境界硬锁或门票费；难度使用进入时人物境界。每次进入动作生成新的实际秘境，复用路线、节点、斗法、奖励和离境流程；完整通关才保底10份专属材料。查询不创建入口、消耗序号或RNG，未通关离境不发保底。

专属材料可按真实材料属性参与炼器，并使用统一参考材料价；不放进普通坊市或兽潮坊市采购池，普通材料不能代替升级门槛。

## 纯查询与原子动作

`mfGardenInfo` 返回种苗、成熟份数、阈值、自然日增、瓶阶附加、总日增和各批预计天数。`mfQuoteGardenPlant`、`mfQuoteGardenHarvest`、`mfQuoteGardenClear` 供预览和执行共用。实际操作先校验，在候选Game上扣物品、生成日志，最后无抛移动提交。拒绝或技术失败不留下半批种苗或半笔扣款。

前端播种范围为 `1..min(药材行囊数量,本格剩余容量,12)`，后端再次核对。无天赋绿瓶视图仅返回 `{hasTalent:false}`；界面只展示自然成长，不显示未持有提示、储备或收费。

旧 `/api/cave/garden/reserve/deposit` 与 `/withdraw` 保留明确拒绝，不能存入或取出。全新存档不产生储备。迁府前仍须收获或清理种苗；历史余额由下一真实世界日返还，无需旧取出按钮。

## 保存、迁移与校验

`Arts.GreenBottleGrade` 编码为 `player.arts.greenBottleGrade`，缺字段默认0；只允许0至6整数，正阶位必须持有天赋。`garden` 保存 `rulesVersion/initialized/lastGrowthDay/plots/pendingHerbReturns`；批次保存 `count/progressUnits`。

版本1或缺版本的历史灵田先按旧成长阈值、99份总容量、合法草药、地块解锁和归属校验，再保持成长比例迁到新版阈值。每格保留前12份；超量未熟苗记原种数量待返，超量成熟苗记三倍成品待返。旧储备编码成只用于待返的 `legacyReserveStones`。迁移不直接增加背包物品或灵石；下一真实日或成功园艺动作对候选状态原子退还，库存上限不足则保留余量。查询和加载不会重复兑现。

缺整个garden字段使用合法空默认，不补历史成长。现代字段按严格整数、版本、草药引用、每格12份、相应成熟阈值、洞府归属和日期校验。非法旧进度不能通过迁移封顶变成合法资产。

定向入口：`tests/test_cave_garden.cpp::mfRunCaveGardenTests`、`test_green_bottle.cpp::mfRunGreenBottleTests`、`test_cave_api.cpp::mfRunCaveApiTests`。覆盖固定周期、实际升级/扣费、专属秘境真实结算边界、纯查询、过期请求、容量/库存、旧档比例迁移/待返和往返保存；浏览器交互与实际构建由本轮交付记录单独报告。
