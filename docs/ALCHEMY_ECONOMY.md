# 炼丹经济与产量说明

本次调整丹药成品收购定价与有限月度收购预算，并补齐收益、变现和真实产量回归。任务、日常营生、修炼、材料掉落、药材采购价、开炉费、成功率、炉具耐久规则不变。

## 为什么旧规则容易亏损

真实买料使用药材 `sourcePrice`，旧成品收购却使用较低的 `price`。例如化淤丹三份药材实际各9灵石，旧收购公式却各算7灵石。买料27加开炉14，旧售价56：丹术30、无加成时成功率67.1475%，一炉期望收入37.60，扣41成本及0.5耐久摊销后亏3.90。

另外，兼容函数 `ecoSalePrice` 把丹方中的中文药材名称当作 ID 查找，无法计算材料成本，与实际 `shop::salePrice` 不一致。现在丹药分支直接委托实际收购函数。

## 统一公式

- `M = Σ 药材采购基价 × 配方数量`。采购基价取 `sourcePrice`；无该字段时沿用坊市回退值 `20 + 药材品阶 × 15`。此处是完整原料价值，不因玩家已有库存而视为免费。
- 单炉开炉费 `F = 8 + 丹药品阶 × 6`，保持不变。
- 单枚收购价 `P = round(max(既有价格下限, (M + F) × 2.2) × world.market)`。旧制作溢价为1.6；旧定价曾误把 `RecipeDef.value`（疗效数值）用作价格下限，本轮保留此下限，避免顺带降价既有丹药。
- 成丹率 `p = clamp(0.46 + sqrt(丹术) × 0.045 + 主修功法成丹率 + 离火门0.08 − 品阶×0.035, 0.1, 0.95)`，保持不变。
- 成功产量 `q = clamp(1 + floor(汇总额外成丹系数 + 1e-9), 1, 4)`。失败产量为0。
- 期望产量 `E[q] = p × q`；期望售出收入 `E[R] = p × q × P`；买齐材料时的期望净收益 `E[利润] = E[R] − 实际买料报价 − F − 耐久摊销`。

商贾/声望折扣、所在地、行情会影响实际买料费，完整原料采购和缺料采购仍由 `materialQuote`/`marketList` 实时报价。下面例子统一常价1.0、无采购折扣、普通炉每炉损耗1点，修炉20/40折合0.5灵石。高阶炉免损规则生效时无需这0.5。炉具购入、旅行、机会成本未计入。

零售成药仍由 `potionBuyPrice` 保证至少按当前收购价的1.25倍报价，因此提升成品售价也提高零售价。商贾及最高声望折扣不能绕过这个下限。没有新建前端价格算法。

## 分层月预算与实际兑现

月预算集中在 `ecoMarketBudget(game)`：`B = max(声望基础额度, 当前市场层级及以下的最高单枚丹药收购价)`。声望基础额度仍为 `min(2400, 400 + 8 × max(声望, 0))`。最高单价直接调用统一收购函数，随真实药材成本和当期行情更新，不另造价格表。

市场层级由 `ecoMarketTier(player)` 给出，按大境界分级；最终化神同时覆盖五六品，避免六品要求游戏中不存在的更高境界。此层级只决定收购流动性，不开放高级药材采购或绕过炼丹、丹炉条件。

| 人物阶段 | 市场最高品阶 | 无声望、常价月预算 | 代表最高单价 |
| --- | ---: | ---: | --- |
| 炼气 stage 0–2 | 1 | 447 | 洗髓丹5002：447 |
| 筑基 stage 3–5 | 2 | 3034 | 续命丹5119：3034 |
| 金丹 stage 6–8 | 3 | 16689 | 该层级最高单枚：16689 |
| 元婴 stage 9–11 | 4 | 85606 | 该层级最高单枚：85606 |
| 化神 stage 12 | 6，含5品 | 3564097 | 该层级最高单枚：3564097 |

这是**整个月的资金池**，每次真实出售按全额扣减，不是每笔交易都会补满。例如无声望炼气常价447资金可买4枚化淤丹，余87后拒收第五枚；也可一次收一枚洗髓丹，随后余额为0。低阶高声望仍至少保留旧2400基础额度。同类需求仍为8～14枚/月，不因高价丹或增产而消失。

初始化与每次跨月使用同一预算函数。同月重复打开面板、报价、刷新、晋阶或重新读档均不补钱；存档中的剩余现金原样保留。行情/声望/境界变化导致新预算提高时，需等下月补资。`marketCash` 是本月实际剩余，`marketBudget` 是按当前条件计算的换月预算；两者不可互换。声望页面使用相同预算和服务端规则说明。

对应市场层级在补资后，至少能完整收购一枚该层级的任意丹药，但不保证该月所有增产丹都立即售出。低阶人物即使获得高阶丹，也不能透支低阶资金池，须等待境界和新月资金达到门槛。上面的期望收入因此表示有足够需求和剩余资金时的售出价值，不是逐炉自动发钱。

养气丹5102需要三品补天芝，九转丹5202需要更高阶配料。这些配料仍不在普通坊市出售，不能把表中源价格当成可无限采购报价；须沿既有探索/交易来源获得。高阶预算只解决成品无法整枚出售的断层，不扩大材料供应或取消投入。

## 验证与接口

新增 `tests/test_alchemy_economy.cpp`，入口 `runAlchemyEconomyTests()`，纳入主测试程序后执行。覆盖：

1. 真实药材报价与一至三品代表丹方收益；高阶材料采购仍被拒绝。
2. 全部零售丹药在行情0.88、1.0、1.16，以及无/最高声望、无/商贾折扣组合下买价高于卖价；真实买入再出售净亏损。
3. 旧报价、坊市报价、实际收购一致；商人资金及每月需求限制仍生效。各境界和三档行情验证整枚售出、月耗尽拒绝、次月再售，低阶/晋阶/读档不能凭空充值。
4. 丹童/悟道/功法产量叠加、整枚取整与上限；即时和年度真实随机成功/失败结算。
5. 1/3/5/10炉的预扣费、材料、耐久、冻结产量与存档往返，结算不二次扣费。
6. 真实 `/api/state` 的 `brewOptions` 增加 `sellPrice`、`expectedOutput`、`expectedSaleIncome`，报价查询保持只读。后两项是期望值，不表示必然成丹或当前商人有足够现金；经典和手机炼丹页直接展示这些权威字段，缺字段显示待报价。

本文件计算表由当前真实丹方和药材表提取，数值例子不是蒙特卡洛或自然游玩收益证明。测试执行结果以本次整合构建的日志为准。
