# 离线战斗数值验收

`tools/battle_swiss.cpp`是仅供开发使用的独立诊断程序，链接本轮Visual Studio生成的`nzcore.lib`。它不加入正式游戏目标、不添加游戏入口、不启动HTTP，不读取或写入任何玩家存档。输出只含隔离内存牌局和诊断JSON。

## 口径

五个大境界初期分别测试：stage 0、3、6、9、12。每境界有三个相互区分的数据集。

- **主瑞士赛**：六宗真实`artNpcLoadout`普通弟子与`combatProfileId`完整传承各一人，加体、火、木、神、金五种妖兽，共17名；七轮按胜/平分与Buchholz配对，每轮八场。禁止妖兽互战，优先不重复；不得不重赛时显式记账。
- **均匀NPC矩阵**：六宗普通/完整共12名修士分别对五种妖兽，另六组同宗完整对普通，共66项比较。这是判断“完整传承强于普通、普通接近妖兽”的主要证据。
- **玩家建议配装补充**：八种Lab流派分别测试初始对完整、初始对体兽、完整对体兽。它仅说明建议配装，不作为真实NPC梯度结论。

每项比较使用种子31、73、137，每种子双腿。人类对人类交换座位，用真实影身双方快照消除普通PvE的敌方1.45倍血量差；两方诊断副本统一遁速，交换座位也交换先后。妖兽始终使用真实普通PvE、真实`BeastActions`和1.45倍血量，两腿分别控制修士先手、妖兽先手，绝不制造妖兽可玩模型。

两方修士均使用公开`mfBattleNpcCardPriority`、真实灵力、冷却、手牌UID和真实`battleTurn`。普通行动上限为`CommonSectActionBase + major`，完整为`ChampionSectActionBase + major`，受核心上限约束。敌方影身计划仅保留相同上限的真实规划前缀；不会让普通NPC使用影身24次行动预算。评分只看当前手牌，沿用核心真实抽牌/连招预演，没有另加窥牌或补牌逻辑。

每轮一名修士空轮，不虚构胜场或加分；妖兽场数较多，因此**瑞士榜只展示，不直接当实力排名**。矩阵对手与局数均匀，输出纯胜率和含平局半分的`leftScoreFraction=(胜+0.5×平)/局数`。所有胜率是固定诊断政策下的结果，不是玩家人口胜率。

## 真结算与证据

全流程调用真实C++规则，不复制JS伤害公式。逐张出牌记录真实手牌、费用上下文、预览原始伤害、实际损血；结束回合记录敌方冻结计划、DOT、护盾及逐段妖兽意图。查询与实际来伤共用规则。

真实回合结束后有静养或木道恢复时，最终净HP差包含后续回血，不直接误报为意图不符，单列`postHealNetHpDeferredChecks`。普通PvE结局会移除Battle，终结帧无法直接观察的精确伤害单列`pveTerminalUnobservable`，不把预览冒充已观察事实。24轮真实平局、互相阵亡平局、诊断上限中断分别记录；诊断中断不记成输赢。

完整五境运行共4380局：瑞士1680、均匀矩阵1980、Lab补充720。任何非法动作、预览差异、禁配兽兽、诊断中断或未完成牌局都令退出码为2。正常完成为0；CLI/文件/内部错误为1。重赛仅记账，不能静默重复。

## 运行

先由当前`visual-studio/ningzhou.sln`构建Release版真实库，再用相同MSVC、C++20、UTF-8和运行库选项编译诊断源，链接`build-vs-share/Release/nzcore.lib`以及`Ws2_32.lib`、`bcrypt.lib`。修改模型后必须重建库并重新链接诊断exe，不能只更换磁盘上的静态lib而复用旧exe。

```text
battle-swiss.exe --output tmp/battle-swiss-final.json --build 本轮标签 --library-sha 本轮lib的SHA256
```

可附`--stage 6`只做单境冒烟。输出保存政策版本、构建标签、库SHA、每个参赛者的真实功法/神通/节点/HP、每次配对/种子/动作、矩阵与瑞士榜，便于比较下一轮改动。临时大报告不加入正式资源或Git。

`--mode mirror`仅跑六宗普通组内与完整组内互打：每组15个无自身比较×3种子双腿×五境=900局，输出10个有方向的6×6胜/平/负矩阵、自身格为空，以及各宗30局的纯胜率与含平得分率。`tools/summarize_battle_mirror.py`可输出Markdown、300格方向CSV及60行分组汇总CSV。组内整体含平得分率恒为50%，不能据此声称流派平衡，必须检查各宗分布及具体对手。

`--mode matrix`仅跑均匀真实NPC矩阵1980局；`--mode swiss`仅跑五境瑞士赛1680局；缺省`--mode full`保持原4380局。便于针对新变化补验，避免无关重复跑全套。

## 本轮结果

当前验收为`final-roundend50-goldcost4-vs37770`：金罡斩的实际减费边界和回合末弃牌护盾50%已包含在同一库。五境4380局见[数值报告](BATTLE_BALANCE_RESULTS_2026_10_15.md)，同组900局与全部6×6矩阵见[六宗互打报告](BATTLE_MIRROR_RESULTS_2026_10_15.md)。V4与仅调整费用的中间候选均为历史，不能用来替代当前验证。

两套报告分别由`tools/summarize_battle_swiss.py`与`tools/summarize_battle_mirror.py`生成；输入JSON必须记录相同的真实库SHA。`--historical-note`可将被替代的快照标成历史。CSV分别保留均匀矩阵15行、瑞士榜85行、有方向的组内格300行和分组汇总60行；阶段性峰值与单格6局的小样本限制一起报告。
