# 五城天机阁执事与材料渠道

普通坊市的一二阶新矿物共64种，炼气可买一阶，筑基起可买二阶。三至五阶新矿物共96种由五城天机阁执事出售。妖兽皮鳞、骨、爪、眼、心五部位不放进商业货架，实际掉落尚待接入。绿瓶专属材料保持专属来源。

执事是独立社会服务目录，不属于随年份成长、游历、死亡和服丹的NPC群体。身份稳定，姓名、境界、驻地在界面明确显示；货架与其私人行囊完全分开，不需要新增存档字段。每座既有经济城市一个分号，境界只表达身份，不决定玩家购买资格。

## 固定价

矿物、药材采用目录本地基价的3倍；不读取sourcePrice，不应用行情、声望、商贾或本地优惠。三/四/五阶新矿物为216/384/600灵石。药材按实际HerbDef.price登记，不根据现实地点重新计算。

突破丹按完整丹方原料本地基价之和的12倍。普通丹药售值会受行情影响；存档合法行情上限为10，对应普通原料价格最大约5.5倍、成丹基础售值1.5倍。12倍覆盖各份舍入误差，避免提前购买突破丹后直接出售形成确定套利。材料和草药的既有出售入口不开放直接出售；制作成丹、炼成法器仍是原有生产结算。
