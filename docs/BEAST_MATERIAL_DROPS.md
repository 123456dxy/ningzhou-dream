# 妖兽五部位炼器材料

## 修改前影响记录（2026-10-18）

| 项目 | 范围 |
| --- | --- |
| 目标 | 将已登记但没有来源的五部位材料接入真实妖兽胜利结算；每只对应属性、品阶的妖兽各掉兽皮鳞、妖骨、牙爪、妖目、妖心一份。 |
| 权威入口 | `battleFinish` 处理非秘境胜利；`dungeonBattleComplete` 在核对冻结入口/节点后处理秘境行囊。新 `exploration/beast_loot.*` 提供统一白名单与入袋规则。 |
| 调用方 | 猎妖委托、野外驱妖悬赏、守药妖兽奇遇、兽潮、秘境普通兽战和妖兽首领；排除人类、切磋、留影、撤离与失败。 |
| 数据契约 | 复用 `fm-{1..5}-{属性}-{yang|yin}-{skin|bone|claw|eye|heart}` 和既有 `arts.materials` / `run.materials`；不新增持久字段或路由。 |
| 属性与品阶 | 由战斗冻结的敌方大道与实际小境界决定；`stage/3+1`。体道妖兽明确使用气/混元材料，不使用玩家境界抬高战利品。 |
| 运行条件 | 串行真实战斗收尾才发放；阴阳在只读规则中由现有种子、战斗随机快照和冻结战斗上下文确定，不推进活动 RNG 或日历；不包含玩家姓名，同名妖兽可随战斗随机快照得到不同阴阳。每只五部位采用同一阴阳。 |
| 兼容 | 原材料 ID 与五维保持不变。普通坊市一二阶矿材、执事三至五阶矿材继续走已有商店规则；旧妖兽随机矿材奖励由五部位取代。秘境行囊白名单增加实际掉落的部位，仍保留既有矿材/专属材料校验。 |
| 验证 | 五品阶八属性、阴阳与五种唯一部位、人物高境进入低境、读取无副作用、胜负/重复收尾/撤离、真实猎妖与秘境行囊→存读档→离境结算、容量边界。 |
| 同步项 | 内容来源说明、制作/探索模块 README、定向 C++ 测试与 VS 工程源列表。两套前端使用已有材料目录及行囊视图，无新计算公式。 |
| 搜索证据 | `enemyBeast`、`beast = true`、`battleFinish`、`ecoHuntEnd`、`societyWildEnd`、`adventureBattleEnd`、`dungeonBattleComplete`、`bankMaterial`、`AcquisitionPending`、`BeastDrop`、`run.materials`、材料 codec/状态校验和前端 `sourceNote`。 |

实现结果与本轮实际检查将在完成后补充；本记录不是已通过验收的声明。

## 结算行为

| 场景 | 行为 |
| --- | --- |
| 猎妖委托、兽潮 | 开战动作随机八种属性之一，冻结到真实对手大道；对应材料属性可以在对手信息与炼器材料来源中辨认。 |
| 药径妖兽、野外驱妖 | 保留事件/悬赏已冻结的妖兽风格；不额外重抽材料属性，原赏金与药材奖励保留。 |
| 秘境妖兽与妖兽首领 | 五部位进入探索行囊，离境结算；普通兽战不再另送一份随机矿材，宗门精英继续其原有奖励。 |
| 旧路线秘境 | 版本1敌人仍按冻结入场境界生成，部位行囊允许至该路线真实首领的品阶；版本2继续受入口境界限制，两者均拒绝高于合法敌阶的部位。 |
| 秘境主动离境 | 携回已获得的全部五部位。 |
| 秘境撤离或非致命战败 | 沿用每种材料数量除二向下取整；若某种只有1份，该种变为0。死亡则遵循原有探索行囊丢失规则。 |
| 矿材 | 商店渠道不变；妖兽旧随机矿材奖励已替换为五部位，宝箱和其他非击杀来源未在本次移除。 |
| 背包容量不足 | 任一种部位达到数量上限时，整组五部位不部分发放，并产生明确纪事；秘境入袋同时检查日后永久背包兑现容量。 |

同一胜利的非秘境入口只在 `battleFinish` 调用一次，随后清空战斗；秘境入口在核对 `run.phase/site/current/visited` 后调用，随后转入奖励阶段，重复旧战斗回调不会再发放。
