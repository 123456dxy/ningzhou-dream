# 现有秘境探索改良与低阶扫荡

日期：2026-10-15。本轮在既有秘境状态机上迭代路线、事件、遭遇与奖励，不代表分境界特殊秘境、首通附魔或天机阁功法线索方案已实现。

## 玩法方向

参考《杀戮尖塔》在危险/安全路线、不同敌人、卡牌和遗物之间的取舍；本项目具体事件、敌人与数值自行定义。[开发者发布的Steam介绍](https://store.steampowered.com/app/646570/Slay_the_Spire/?l=english)

新入场使用路线版本2，仍为9～13层、每层三条路线。中途同层混合战斗、精英、事件、宝箱、游商和营地，位置按入口种子变化，首领前保留营地。路线页展示当前可达节点、后续去向、精英风险、具体敌人机制与事件取舍，给玩家规划补给或争夺遗物的依据。

旧在途探索缺少`layoutVersion`时仍按版本1校验，不在更新后重绘已有连线。新版本仅在真正入场时写入2；读取预览不生成入口、不给奖励、不推进活动RNG。

## 六种事件

| 事件 | 可选择的取舍 |
| --- | --- |
| 涸泽灵泉 | 恢复25点健康度，或付出10点换探索灵石 |
| 噬血祭坛 | 付15点健康度取一件临时遗物，或恢复10点 |

每个事件都允许不选收益继续前进。气血代价必须至少留下1点，满血时纯治疗选项禁用；灵石仅消耗本次探索行囊。临时卡和遗物离境消失，不授予永久神通、功法、悟性或悟道点。60张上限、未知/过期选项、重复领取、被改写的冻结奖励与卡UID冲突由后端明确拒绝。

## 六类妖兽与精英

岩甲守卫、焰息异兽、瘴毒异兽、摄魂异兽、迅爪掠食者、蓄势猛兽分别复用现有凝甲、灼烧、毒息、扰灵、穿盾与重爪蓄势机制。炼气尚未解锁的动作会明确说明，不假装已生效。精英使用六宗真实普通构筑；不冒充完整传承高手，也不借用世界NPC身份、背包或服丹。

路线预告与开战共用同一`DungeonEncounter`。普通战为入口低一小境，精英和首领同入口境界，健康系数仍为65/90/115；不根据玩家临时提升的境界暗中抬怪。战斗界面继续显示当轮真实意图与多段伤害。

## 收益与费用

所有新收益按入口标注境界分档；高境人物进入或扫荡低境入口不会抬高奖励。沿途材料使用入口适阶池，没有合法同阶草药时安全向下降档；六阶药材仍可通过原定向情报获取。新主奖励仍在入口生成时冻结，已承诺的旧冻结奖励保留原值。

## 一键扫荡

目录与地图的入口保留“正常探索”，旁边增加扫荡。后端复用正常入场资格，要求人在入口、窗口有效、没有工作/抉择/战斗/其他探索，并高出入口至少一个大境界。同大境界只高小境不能扫荡。

扫荡建立合法已通关探索，直接打开原冻结终奖选择，不替玩家随机选择。定向情报仍保底目标材料10份；普通入口不凭空生成沿途材料、遗物、击杀统计或战斗灵石。手选后走正常离境流程累计结算1世界日；遇事暂停沿用已有继续入口。重复请求不能再通关或重复发奖。

## 实现边界

- `dungeon.cpp`保留入场、路线、通关与退出编排；扫荡报价/执行共用入场规则及候选写集提交。
- `dungeon_events.*`管理事件目录、冻结选项、报价、原子结算和领域校验。
- `dungeon_encounters.*`共用真实战斗规格与预告；不新增全局妖兽机制。
- `dungeon_reward_rules.*`集中境界奖励和材料池；前端不推导品阶、数量、费用或资格。
- `DungeonRun.LayoutVersion`同步codec/结构/领域校验，缺字段默认1。
- HTTP新增`POST /api/dungeon/sweep {id}`，其他操作复用原choose/claim/leave。
