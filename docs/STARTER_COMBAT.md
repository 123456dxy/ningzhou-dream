# 新角色初装与劫修诊断

## 正式游戏初装

真正新建角色在 `ensureArts` 首次初始化时携带金芒刺、焰火诀、水灵盾、聚气。四个额外槽各生成两张牌，固定普通攻击与守势各五张，实际牌堆18张。

职责分别是一费直伤、持续灼烧、一费护盾和零费回灵。所有神通都来自现有炼气可用目录，费用与效果继续由真实战斗引擎计算，没有增加隐藏攻击、满层功法、悟道节点或装备。

原本已知的御剑诀、水灵盾、回春术、明心咒、换念诀、忘机咒全部保留，再新增金芒刺、焰火诀、聚气。玩家可以自行换回治疗或抽牌。`ensureArts` 的已初始化分支不自动更换已有角色配装，也不追赠新初装；主动卸空神通的选择继续保留。

这属于完整本地游戏的真实建角流程，不是独立斗法试炼场的八种满预算流派模板。

## 诊断方法

工具为 `tools/starter-battle-probe.cpp`，只生成隔离内存角色与指定路径的 JSON 报告，不读取玩家存档，不连接现有游戏服务。诊断工具不加入正式游戏构建目标。

每个样本调用真实 `createGame`，显式无天赋、资质分配10点、体魄0，保留吐纳一层、无辅助功法、无悟道节点。30个种子固定为 `31 + 997 × i`，`i=0..29`。

从 `adventureEvent("bandit")` 生成实际山道劫修抉择，隔离副本仅把 `pending.adventure.stage` 设为规则允许的同阶0或高一小境1，随后调用 `adventureChoose("fight")` 和 `battleTurn`。没有复制 EnemySpec、伤害、盾量或持续伤害公式。天然事件高一小境概率为18%，本批原生事件为6/30；边界矩阵刻意对每个种子都测两档，不能用矩阵比例解释自然遭遇概率。

三种命名策略固定后比较所有候选，没有为新配装重新调整权重：

- `NpcPriorityV1`：正式 NPC 牌优先级用于玩家手牌，玩家仍保留正式灵力与施术预算。该策略优先防御，属于低水平替身。
- `VisibleGreedyV2`：使用公开的打出伤害、疗盾、回灵和抽牌数估值，给破盾伤害价值；没有未来牌序搜索。
- `VisibleTwoStepV2`：至多预演两张当前已经持有的非抽牌神通，调用真实施法及公开敌方意图，低血更看重生存。抽牌只按公开张数估值，不执行抽牌预演、不读取未来牌堆或 RNG。

非法动作和诊断上限中断会使工具失败，不混入胜负统计。所有实测均正常结束。wild 战24回合判负且结束人生，不能记作切磋平局。

## 30种子结果

下表每格为30局胜局数。候选都只改变四张额外神通，功法、节点、属性和对手保持不变。

| 四张额外神通 | NPC优先级同阶 / 高一小境 | 可见贪心同阶 / 高一小境 | 两步可见同阶 / 高一小境 |
| --- | ---: | ---: | ---: |
| 金芒刺 / 焰火诀 / 水灵盾 / 聚气 | 25 / 6 | 15 / 1 | 19 / 5 |
| 金芒刺 / 上清印 / 丹阳印 / 回春术 | 28 / 9 | 14 / 0 | 22 / 5 |
| 上清印 / 丹阳印 / 水灵盾 / 聚气 | 30 / 24 | 28 / 13 | 27 / 17 |

因此选用金芒、焰火、水盾、聚气作为新角默认：同阶三种策略为50%、63.3%、83.3%，高一小境为3.3%、16.7%、20%，保留打法和抽牌差异。两步可见策略的同阶11局失败中，6局为24轮超时，另5局气血耗尽；高一小境25局失败中4局超时、21局气血耗尽。

毒火双印候选在同阶和高一小境明显更强，适合作为玩家自行学习构筑的方向，没有作为默认初装直接发放。机器人胜率只描述这些种子与策略，不能视为人类最优胜率或无法战胜的证明。

初轮仅替换御剑为金芒/崩山时，低水平策略改善很小且不稳定。旧 `VisibleGreedyV1` 还错误地把破盾攻击视为零效用，产生空过，相关结果已废弃。早期线性保血的两步策略同样会守到超时。生产数值没有为这些失误而提高。

## 真实量级与回避

新角炼气初期气血144、灵力3、遁速20；同阶劫修气血208、遁速20、玩家先手，使用吐纳一层和御剑诀/剑意激发，每轮最多2动作。高一小境劫修气血243、遁速28，敌人先手。示例种子31同阶首轮预告21伤；高一小境开场先造成24伤，玩家出牌前剩120气血。

无悟道和装备时，普通攻击为11伤/1费，御剑诀19伤/2费，金芒刺18伤/1费；守势17盾/1费、水灵盾26盾/1费，回春术完整20血/2费，聚气实际回1灵力/0费。以上为实际后端预览，未修改费用或公式。

30个事件副本选择“避开冲突”均不受伤、不花灵石；“交出路资”扣最多12灵石后脱身。玩家可以主动避免打不过的劫修。

现有语义限制单独保留：事件对手 `lethal=false` 导致实际斗法撤离保证成功，但 wild 败北会结束人生；灵舟说明与非零旅行截杀率也不一致。本轮没有修改逃离、死亡或旅行。普通宗门 NPC 对妖兽的战绩使用另一套真实配装，不能拿来代替本页的新角色诊断。

## 验证边界

`tests/test_combat_design.cpp` 覆盖真实新建初装、保留原已知神通、重复初始化不改 RNG/不重复添加、已有配装不被覆盖，以及通过真实劫修事件生成合法18张牌堆。该定向测试由统一测试入口继续收集。

新测试先链接原冻结库确认预期失败，再用当前 `arts.cpp` 的隔离对象覆盖后链接同一库，`runCombatDesignTests` 42项通过；没有为此重编主工程或改动现有服务。
