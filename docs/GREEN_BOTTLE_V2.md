# 小绿瓶永久品阶改版

2026-10-15 用户本轮要求；一年按 360 世界日。本文件记录实现与验收口径，尚未执行的检查不得写为通过。

## 规则

- 天赋稳定 ID 为 `greenBottle`；只有持有者可看到、升级、进入其专属灵材秘境。
- 品阶 0～6，初始 0。每次升一级，一次性支付，永久有效，无日费和维护。
- 目标阶位 1～6 的灵石分别为 2000、5000、8000、10000、20000、40000。
- 四/五/六阶另需专属秘境灵材。用户范围为 40～60、80～120、160～240 份，本轮取中值 **50、100、200**。
- 四阶灵材秘境要求当前瓶阶至少 3；五阶至少 4；六阶至少 5。六阶瓶仍保留六阶入口。通关保底10份，不能用普通坊市材料绕过秘境接口；沿用真实秘境探索，不虚构额外收费或人物境界硬锁。
- 瓶阶 0～6 的每日附加成长固定为 **0、45、85、150、250、420、700**。
- 洞府档位寻常/灵脉/聚灵仙府的自然日增为 **20、40、60**。
- 总日增仅为 `洞府自然日增 + 瓶阶附加日增`，所有世界日后台生长，外出也生效。
- 一～六品成熟点固定 **18000、45000、112500、281250、703125、1757812**。
- 每批成熟天数为 `ceil(max(0,成熟点-当前成长)/总日增)`；报价和真实日结算共用规则。
- 每格最多 **12** 份，收获倍率仍 **3**，满配8格一轮最多288份。追加批次各自成长，不继承已有进度。
- 灵气配给只影响闭关修炼，退出灵田所有成长、成本、预报逻辑。
- 删除格内储备机制（存入、取出、余额、日费、资金不足回退等），旧操作明确拒绝。禁止在只读查询中返还旧储备或改变品阶。

## 界面

- 显示自然/绿瓶/合计日增与各批预计成熟天数。
- 有天赋才显示当前瓶阶、下一阶日增和周期改善、升级灵石/材料需求及已有量。
- 升阶按钮文字固定为「投入大量灵石，为小绿瓶恢复些许灵性」。
- 无天赋只显示自然成长，不出现绿瓶升级或专属秘境入口。
- 不显示储备、按日扣费、灵田灵气方案和该方案的预计天数。
