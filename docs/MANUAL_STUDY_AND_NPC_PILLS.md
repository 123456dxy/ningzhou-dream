# 功法参悟与 NPC 服丹规则

## 参悟报价

`progression/manual_study.cpp::manualStudyInfo` 是功法参悟唯一报价入口。目录下一层提示、工坊开工灵石与时间，以及旧年度结算的灵石消耗均使用该报价；抄本购买售价独立计算。

- 一阶第一层：40 天、24 灵石。
- 已修层数为 `L`（0～4）；功法阶次为 `T = stage / 3 + 1`，由功法要求的大境界决定，不随角色境界变化。
- 未折扣耗时：`40 × 1.2^L × 2^(T-1)`；灵石：`24 × 1.2^L × 2^(T-1)`。
- 悟性时间系数：`clamp(1 - (悟性 - 10) × 0.01, 0.6, 1.5)`；“过目不忘”天赋另乘 0.8。灵石不受悟性折扣影响。
- 最终天数和灵石向上取整（扣除 1e-9 仅抵消整数边缘浮点误差），耗时最低三天。层数与阶次在指数前钳制；已满五层报价为零并拒绝开工。
- 开工冻结 `Job.total` 与 `Job.cost`，完成时提升一层且不再次收费。旧存档已开始的安排保留原报价。

例：悟性 10、无“过目不忘”时，一阶五层依次消耗 40 / 48 / 58 / 70 / 83 天，以及 24 / 29 / 35 / 42 / 50 灵石；二阶第一层为 80 天、48 灵石。

## NPC 服丹边界

`social/npc_consumables.cpp` 管理选择和 NPC 增量；`artPillUseInfo` 与 `artApplyPill` 复用玩家的真实药效、耐药、丹毒和属性上限。`NpcPillState` 只保存服丹记录、常驻属性和下一次准备，不包含玩家库存或战斗。

- 仅在年度行动开始、收到赠丹、真实战斗开局这三个动作边界服药。查看人物、生成构筑、读取报价、迁移在途战斗均不服药或消耗随机数。
- 年度和战前每次最多三枚，赠丹只检查本次赠送的一枚；每枚服用后重新判断收益。优先处理高丹毒、重伤和寿元将尽，其次突破、修为、常驻属性及流派收益。
- 悟道丹按丹方的大道 ID、五行及剑气战斗丹按稳定丹方 ID 限定流派。实际构筑服从宗门大道；通用增益可用。不因修改丹药名称或说明改变流派判断。
- 战斗丹留到真实开局才使用，同类无额外收益不重复服用。准备转入真实敌方战斗状态后清空，读档不会再次扣药。NPC 抢先行动时保留开局丹药护盾，供玩家首轮攻击消耗；随后按正常回合规则清除，不重新发放。
- 实际从 `bag["potion:" + id]` 扣一枚；库存为零、负数、未知 ID、妖兽、死亡角色都不会服药。满血、属性封顶、耐药耗尽、丹毒过高或无适用收益时保留物品。
- NPC 不主动越阶服普通丹；突破丹须满足对应境界与修为门槛。突破准备增加一次 6 个百分点，结算后清除。原有通用突破丹库存继续使用原规则。
- 自然化毒为每年 1 点，丹道二层为 5 点。丹毒超过 20 时与玩家共用修炼减速曲线，最低五折；80 及以上须先化毒。本世资质丹最多加 10，额外寿元最多 250，气血丹加成最多 200 个百分点，心境/神识/额外遁速最多 500；实际贡献提前封顶时也不浪费丹药。
- 寿元丹先于年度寿终判定，后续突破保留 `lifeBonus`。心境参与 NPC 突破，神识、体魄、遁速与战斗准备进入真实构筑；悟道经验和悟道点可按本流派自动补点。驱妖效力减半 NPC 年度游历遇险概率；诱妖液属于主动采集，不自动当丹药喝。

旧档 `pillsUsed` 迁移为每味至少用过一次，不重放属性；已用资质丹计入额度。新字段有结构和范围校验，非法导入不覆盖现有状态。

## 回归入口

`tests/test_study_npc.cpp::runStudyNpcTests` 覆盖指数报价与折扣、报价/扣费一致、极端输入、库存/丹毒/耐药/属性上限、流派适用性、只读不变性、双方分别先手的真实战前效果、首轮护盾与后续回合清除、年度寿元、在战存档及旧档迁移。
