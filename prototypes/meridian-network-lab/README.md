## 已确认的玩法

玩家操控一股真气，在约36穴的完整经脉网上选路。每穴独立耗气、成功率、分数、冲击次数与冲破效果；首次成功才得分并触发效果。失败耗气、扣目标次数，留在原处；次数耗尽闭塞，可改道。任、督、冲各有两个候选主关，通过各区任一主关后回丹田归元结基。

基础真气100，每颗筑基丹增加15（试玩0～6颗）；灵核提供全局一次恢复刚失败穴剩余冲击次数到上限的机会，不退还真气。普通穴2次、主关3次。原型天赋：先天道体冲穴少耗1气、道心坚毅主关成功率增加10个百分点。默认一颗丹、携带灵核、凡身。

普通穴／窥见／蓄势／聚气／通络／精炼／主关的基准分别为：4气85%4分／4气90%2分／5气80%3分／5气75%2分／6气80%3分／7气65%8分／8气70%10分。

窥见揭示两层穴位详情；蓄势使下一目标成功率增加20个百分点，同一目标重试与灵核恢复保留，成功或改冲另一目标后结束，不叠加；聚气首次回12气；通络开启指定近道。已通穴相邻回走耗1气，不重复奖励。地图轮廓公开，未揭示节点不向前端发送真实名称、数值与效果。开局近处两层与主关可见。

归元额外20分，最终根基为累计分数、最高120。超过100分的部分每点增加1基础生命，斗法等效乘2.4。结果仅在成功归元后结算，永久定型；撤退无奖励。

## 上手

先熟悉三关与归元，不必第一局追120分。可在准备里选2颗丹、携带灵核、先天道体；选穴只预览，右侧按钮才提交。左侧任关、上方督关、右侧冲关各冲开一处即可，重复冲另一个同区主关只为额外分数。三关皆通后，沿已通路线回丹田，再确认归元；结算额外加20分。

已通路每步回走仍耗1气，界面不显示返程预算辅助提示。不能把真气全部用光，0气且不在丹田时只能收功重来。灵核恢复次数仍需另付冲穴真气。

丹田四个直接入口为气海、会阴、水道与北侧至阳。丹田与至阳双向直通，沿至阳可继续进入巨阙、印堂、天柱一带的中部经脉。
