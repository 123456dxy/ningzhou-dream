# 周天搭建沙盘

独立讨论原型：在5×5棋盘连接经脉，真气沿单一闭环运行；每圈结束暂停，保留气势、紊乱与穴位蓄气，再调整线路。没有接入正式游戏、角色存档、联机或本命奖励。

先运行基础回路，再试着调整功能穴位。丹田、任脉、督脉、冲脉固定，初始外圈已连通；普通经脉可旋转、换直弯或拆除，蓄气、凝元、稳脉各有两个独立元件，同时最多装四个。

- 首圈前自由搭建；之后每圈最多改两格，每个净改动占一息，撤销草稿不扣费。
- 蓄气跟随元件：原地旋转保留，拆除或搬移会散去未兑现蓄气。更换元件不会直接产气或清除紊乱。
- 真气每走一段耗一息。普通时限72息，灵核增加8息。试运是只读预演，正式运行才扣时、更新状态。
- 三关窍本圈均吻合才收下元液；气势不足或紊乱过高时，本圈成果可能散失，已运行时间和状态仍保留。断路、非法编辑或超时则拒绝提交。
- 至少贯通一圈后可以凝基，100分以上每分增加1点基础生命，斗法等效增量为其2.4倍，上限120分；正式凝基后不可补修。

启动：

```powershell
node prototypes/meridian-loop-lab/server.mjs --port 53239
```

默认不指定端口时使用空闲临时端口，只监听127.0.0.1。每个标签使用独立内存会话，刷新可继续，服务重启清空局面。原五行对照仍由`prototypes/zhuji-lab/`单独提供。

规则与隔离HTTP检查：

```powershell
node --test prototypes/meridian-loop-lab/engine.test.mjs prototypes/meridian-loop-lab/server.test.mjs
```

`engine.mjs`拥有所有资格、费用、运行、报价和奖励计算；`server.mjs`仅管理本地内存会话、修订号与请求去重。前端保存编辑草稿，读取后端轨迹做动画，不自行计算真实结算。重复和过期请求不得重复运行，非法或未提交的草稿不得影响活动状态。
