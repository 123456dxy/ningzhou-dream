# 导气冲穴沙盘

独立试玩原型：操控一股真气，在当前经脉图选择相邻穴位前进，或先蓄气、泄气调整气势。保留五行凝练与闭环搭建两套旧原型供对照，不改正式游戏和玩家存档。

当前段地图完整可见，后续经脉进入时才揭晓。气势跨穴、跨段保留，进入穴位时吻合气势窗口才得额外底蕴；通过后穴位的气势变化始终生效。可直接走终点，也可绕经旁穴争取收益。

- 基础气势6，范围0～10；基础14次行气。
- 蓄气最多＋2、泄气最多－2、移动到相邻穴各耗一次行气；抵达出口后进入下一脉不耗次数。
- 后端始终保留走完余程所需的最少次数，不能因过度调气或绕路产生必败局。错过窗口只失去本穴额外分，仍可前进。
- 任、督、冲三脉贯通自动结基。未完成时分数为预计；最终100分以上每分＋1基础生命，斗法等效增量×2.4，最高120分，结果不可补修。
- 筑基丹每颗增加1点初始气势（受10点上限约束），灵核增加2次行气，道体增加1次行气，道心坚毅每段首次有效调气不耗次数。

前端只提交移动/调气选择并展示后端报价、轨迹与结果。资源、次数、资格、最短余程、吻合与奖励均由同一引擎计算。动作带修订号和请求标识，非法请求不部分执行，重复请求不重复走气或发奖。
