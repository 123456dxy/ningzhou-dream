# 筑基玩法沙盘

## 方案确认（2026-10-16）

用户已确认两种可选筑基方式，突破前由玩家自主选择：

- 五行凝练：以本目录 `elements` 模式的明亮五行罗盘、逐轮随机抽气与术式组合为基准。
- 周天冲穴：以 [周天冲穴原型](../meridian-network-lab/README.md) 的完整经脉网、单穴冲击与效果连锁为基准，包含丹田北向至阳通路。

这两套玩法作为后续正式接入的确认版本；如需调整玩法或数值，另行讨论。本目录内旧的三脉选路模式，以及回路搭建、七穴选路等中间原型，仅保留作历史对照，不属于本次确认的两种方式。

当前成果仍为独立试玩；正式角色成长、丹药与天赋、存档及本命奖励尚待接入。下方规则与历史实测按版本保留，旧记录不能覆盖本节确认的方案范围。

当前新会话默认展示五行罗盘版。八轮自然供气依次为6、6、8、4、6、8、4、6，稳灵阵只将其中一组8、4平滑成6、6。灵潮只决定供气数量，每点金木水火土均为20%概率。入关只抽首轮，真实推进才抽下一轮；页面取消整条预报，只提示下轮随机抽取数量。查看、报价、刷新不会重抽或提前揭示结果。

先选术式，再点罗盘对应五行直接施展；相生点击生出方，自动取起点和下一系各2点；五行合一点击中央，每系消耗1点，获得12点凝练。换气先点来源暂存，目标点击才真实扣气，取消和切换术式不会扣气。罗盘报价、费用、下轮随机抽取数量和实际结算由同一后端规则提供；推进预览不返回未来随机五行组成。

新版基础凝液、聚气均需同系2点；聚气使下轮额外随机抽3点，每点五行各20%，允许碰巧抽回投入系。施放时只登记未定属性的数量，进入下一轮才实际抽取；自然气、筑基丹、灵核与聚气使用独立随机流。筑基丹每颗在入关时独立随机抽2点五行灵气，允许重复，抽出的结果记录在本局；查看、报价、刷新不重抽。不能指定筑基丹五行。跨轮保留上限仍为8点，道体为10点，溢出时以五个数字指定保留量。普通施术取消重复确认，永久定型和散去余气等关键提交保留确认。

周天改为任脉、督脉、冲脉三段，基础9步。当前段安全贯通耗2步，温养耗3步加4～8额外底蕴，深炼耗4步加8～12额外底蕴；只在真实进入当前段时揭晓收益。每条可选路线都为后段预留至少2步/段，三段走完自动结基。每颗筑基丹、灵核、先天道体各增加1步，最多12步；道心坚毅使首次温养少耗1步。准备溢出的无效步数由后端提示，不再使用旧真息、压力、潮汐与手动封基规则。

两种方案成功时，超过100分的每1分增加1点永久基础生命，斗法等效生命增量为基础增量×2.4，当前上限120分。周天未完成时的100分是完成全程后的预计基准，未结基或主动退出不发奖励。五行仍60分达标，品质名称与实际生命数值分开展示，不再使用百分比生命奖励。下文所有旧路线和百分比结果均是历史版本记录。

基础生命与斗法等效值仅在独立沙盘内展示，没有写入正式角色或接入正式斗法。

当前版本已移除引灵丹与对应操作，两种模式均不再提供该入口。周天筑基丹只增加行气预算，不进行五行抽气。

在仓库根目录运行：

```powershell
node prototypes/zhuji-lab/server.mjs
```

终端会输出本机网址。默认使用空闲临时端口，也可追加 `--port 18166` 指定未占用端口。服务只监听 `127.0.0.1`，使用 Node.js 自带模块，无须安装依赖。

每个浏览器标签持有独立内存会话，两种方案各自保留进度。刷新可以继续，重启沙盘服务会清空试玩局面。页面只存会话标识，不读取或写入正式游戏存档，不连接现有玩家服务。

`engine.mjs` 在服务端集中计算报价和真实结算；客户端只提交选气与操作。所有报价在副本上执行，动作附带修订号和请求标识，拒绝与重复请求不会重复消费资源。

规则与HTTP检查：

```powershell
node --test prototypes/zhuji-lab/engine.test.mjs prototypes/zhuji-lab/server.test.mjs
```

只涉及独立网页与Node沙盘，没有改动C++源码，因此不需要同步VS工程或构建正式游戏。

## 2026年10月16日追加实际试玩：固定解与准备价值

本轮真实浏览器试玩完成以下两条零准备路线。两条路线均选择凡身、0颗筑基丹，不使用灵核或引灵丹；每次确认前核对服务端实际预览。下面记录的是当前原型中发现的固定解，不是推荐采用的正式游戏规则。

选择「平稳灵潮」。按表手选灵气并执行术式，每轮操作完成后结束本轮；第8轮结束时定型。

| 2 | 同源凝练：木3枚；聚气待发：木、火各1枚；相生合炼：木、火各2枚 | 22 |
| 3 | 同第2轮 | 36 |
| 4 | 同第2轮 | 50 |
| 5 | 同第2轮 | 64 |

| 7 | 同第2轮 | 92 |

实际结果为圆满根基，永久额外气血＋12%。此路线的聚气必须支付木、火各1枚，第2至7轮的同源凝练必须支付木3枚；不能假定自动择气会选中相同配方。第1轮只用两次操作即可进入下一轮，不必耗尽操作次数。

### 本轮设计发现

- A在零准备下已能获得最高品质圆满；110分与120分同为永久额外气血＋12%，不必为品质追到120分。
- B在调和灵潮下，零准备也能获得当前最高品质浑厚。不能据首轮平稳灵潮的8分结果，认定10分必须靠额外准备。
- 两条固定解暴露了准备价值偏弱、固定灵潮容易形成背诵路线的问题。它们用于下一轮讨论玩法取舍，本轮没有据此修改规则；上文首轮验证记录不作为本次追加试玩重新执行的结果。
